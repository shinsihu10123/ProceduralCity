# v0.5.2 Native WebGL Transport

## 목표

기존 2D/2.5D 교통 오버레이를 제거하고 차량과 경전철을 도시 WebGL 장면 내부의 실제 3D 기하로 렌더링한다.

## 구현

- 도시 `roads` 데이터의 월드 좌표, 높이, 방향, 도로 등급 사용
- 동적 `transportBuffer`와 `gl.DYNAMIC_DRAW` 적용
- 기존 도시 셰이더, 태양광, 안개, 깊이 버퍼 공유
- 승용차, 버스, 트럭의 차체·캐빈·유리·바퀴·전조등 메시
- 3량 경전철의 차체·창호·지붕 메시
- 도로 방향과 차선 오프셋을 반영한 월드 좌표 이동
- 도시 시드에 따른 교통량, 차종, 색상, 속도 재현
- 도시 재생성 시 교통 에이전트 자동 재생성
- `ProceduralCityRenderer` 공개 API

## 공개 API

```js
window.ProceduralCityRenderer.getCity()
window.ProceduralCityRenderer.getViewProjection()
window.ProceduralCityRenderer.getTransportSnapshot()
```

## 렌더 순서

1. 도시 정적 버퍼 렌더
2. 교통 동적 버퍼 갱신
3. 동일 view-projection과 조명 uniform으로 교통 렌더
4. 깊이 검사로 건물·도로와 자연스럽게 가림 처리

## 후속 작업

- 연속 도로 그래프와 교차로 연결
- A* 기반 출발지·목적지 경로 탐색
- 신호 주기와 차량 정지선
- 정류장 승하차와 버스 노선
- 경전철 역 정차와 배차 간격
- 차량 선택 및 추적 카메라
- 인스턴싱 기반 대규모 교통 최적화
