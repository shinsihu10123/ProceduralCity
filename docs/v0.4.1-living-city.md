# v0.4.1 Living City

## 목표

정적 도시 생성 결과 위에 시간에 따라 변화하는 이동·시설·환경 객체 계층을 추가한다.

## 구현 범위

- 시드 기반 차량·경전철 에이전트 생성
- 도로축을 따르는 실시간 이동 표현
- 학교·병원·소방서·경찰서·환승센터·공원 POI 생성
- 시설별 수용 규모와 서비스 점수
- 객체 선택 및 상세 정보 검사기
- 교통·열섬·침수 분석 모드와 연동되는 격자 오버레이
- 도시 재생성 시 이동·시설 상태 동기화
- 외부 모듈 연동용 `window.ProceduralCitySimulation` 인터페이스

## 공개 인터페이스

```js
window.ProceduralCitySimulation.reset()
window.ProceduralCitySimulation.getSnapshot()
window.ProceduralCitySimulation.setAnalysis('traffic' | 'heat' | 'flood' | 'none')
```

초기화 완료 시 `procedural-city:simulation-ready` 이벤트를 발생시킨다.

## 다음 결합 단계

현재 이동 계층은 WebGL 장면 위의 독립 캔버스로 렌더링된다. 다음 단계에서는 WebGL 엔진이 도로 중심선, 건물 바운딩 박스, 역 위치와 카메라 행렬을 공개하도록 변경하여 다음 기능을 구현한다.

1. 실제 도로 그래프 기반 경로 탐색
2. 3D 좌표와 화면 좌표의 정확한 투영
3. 건물 클릭 선택과 용도·층수 편집
4. 시설 서비스 권역의 실제 네트워크 거리 계산
5. 강우·고도·불투수율 기반 침수 셀 계산
6. 건물 밀도·표면 재질·녹지 기반 열섬 계산
