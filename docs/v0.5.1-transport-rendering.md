# v0.5.1 Transport Rendering

## 목적

기존 Living City 계층의 점·막대 교통 표시를 차량 형상과 원근 투영을 갖춘 시각화로 교체한다.

## 구현

- 승용차, 버스, 트럭, 경전철의 서로 다른 차체 비례
- 차체, 지붕, 창문, 전면부, 바퀴, 그림자 레이어
- 주행 방향에 따른 회전
- 화면 깊이에 따른 크기 변화
- 도시 평면을 사다리꼴 원근 공간으로 해석하는 투영
- 시드 기반 차량 종류와 외장색
- POI 문자 아이콘과 서비스 권역
- 열섬·침수 격자의 도시 평면 투영
- 교통 오버레이가 카메라 조작을 막지 않도록 입력 통과

## 현재 한계

이번 구현은 WebGL 장면 위에 투영되는 경량 2.5D 교통 모델이다. 점 표시는 제거되지만 차량이 아직 실제 도로 메시의 월드 좌표를 사용하는 것은 아니다.

## 다음 결합 단계

1. 생성 엔진에서 도로 중심선과 차선 정보를 공개한다.
2. 카메라 view-projection 행렬을 공개한다.
3. 차량 좌표를 월드 좌표로 관리한다.
4. 차량을 WebGL 메시 또는 인스턴스 메시로 렌더링한다.
5. 신호등, 교차로 우선권, 경로 탐색과 정류장 정차를 연결한다.
