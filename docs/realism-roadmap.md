# 현실성 고도화 로드맵

## 완료: v1.1 — Reality Engine

- 미터 기반 공간 스케일
- Priority-Flood 배수 보정·D8 유역 누적 기반 수문
- 하천·홍수 위험·경사·개발 적합도
- 지형 비용을 반영한 A* 도로망과 도로 위계
- 가로 전면 기반 필지 분할
- 교량과 경전철
- 다핵 도시 구조
- 접근성 기반 용도 배치
- 8종 복합 건축 매스와 재료 기반 입면
- 공원·광장·가로시설
- 시간대·습윤 환경과 유리·수면·아스팔트 셰이딩
- 인구·일자리·녹지·홍수·경사·망 연결성 지표
- 결정론·수문·필지·렌더 버퍼 자동 검증

## v1.2 — 편집 가능한 도시계획 모델

- 건물·필지 클릭 선택
- 층수, 용도, 건폐율 직접 편집

- 역과 공공시설 이동
- 실행 취소·다시 실행
- 도시 저장과 불러오기
