# Procedural City v0.5 Renderer Renewal

## 목표

v0.5는 기능을 화면 위에 계속 추가하는 버전이 아니라 UI와 3D 렌더러의 책임을 분리하고 도시 자체가 화면의 중심이 되도록 재구성하는 버전이다.

## 1차 구현

- 전체 화면 3D 뷰를 기본 레이아웃으로 전환
- 생성·지표·환경·분석·레이어·지도 패널을 필요할 때만 표시
- 상호 배타적인 대형 패널로 화면 겹침 방지
- 하단 카메라 모드 스트립
- Escape 키로 모든 도구 닫기
- 안개 backdrop blur 제거 및 흐림 강도 완화
- 기존 엔진 ID와 이벤트를 유지하여 기능 호환성 보존

## 3D 모델링 리뉴얼 방향

### 건축물

- base / podium / tower / roof / equipment의 계층적 매스
- 전면·측면별 창호 모듈
- 발코니, 차양, 기둥, 출입구, 캐노피
- 주거·업무·상업·산업·공공 건물별 재료 팔레트
- 저층·중층·고층에 따른 세부도 단계
- 동일 유형 반복을 줄이는 facade seed

### 도로와 기반시설

- 차도·보도·연석을 독립 메시로 분리
- 교차로 형상과 횡단보도 정합성
- 중앙분리대, 버스 정류장, 주차면, 자전거도로
- 교량 상판·난간·교각과 하천 제방
- 가로등·신호등의 야간 발광 상태

### 렌더링

- 객체 유형별 재질 파라미터
- 태양 고도 기반 광량과 색온도
- 창문 발광과 가로등 야간 점등
- 거리 기반 LOD와 세부 객체 생략
- 향후 그림자 맵과 후처리를 추가할 수 있는 render-pass 경계

## 다음 구현 순서

1. 건물 메시 생성기를 facade 모듈로 분리
2. 건물 유형별 3~5개 매스 변형 추가
3. 도로·보도·연석 메시 분리
4. 야간 발광 속성과 날씨 재질 상태 도입
5. 카메라 거리 기반 LOD
6. 실제 성능 측정 후 그림자 적용 범위 결정
