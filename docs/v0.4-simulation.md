# Procedural City v0.4-alpha — 도시 시뮬레이션 계층

## 목표

v0.3의 정적 절차적 도시를 시간에 따라 변화하는 도시 시스템으로 확장한다. 자연환경, 기상, 교통, 시설 운영, 분석 레이어와 사용자 인터페이스를 하나의 시뮬레이션 상태로 연결한다.

## 이번 구현

### 시간과 환경

- 자동 도시 시계와 날짜 진행
- 0.25×, 1×, 4×, 12× 시간 속도
- 봄·여름·가을·겨울 자동 판정
- 온대·대륙성·몬순·해양성·건조 기후 프리셋
- 맑음·흐림·비·눈·안개 자동 기상 전이
- 기후·계절·시간·기상에 따른 온도 계산
- 기존 WebGL 시간 슬라이더와 자동 동기화
- 비·눈·안개·흐림의 화면 공간 기상 표현

### 운영 대시보드

- 인구, 일자리, 밀도, 녹지율, 대중교통 접근률, 직주 균형 KPI
- 도로·철도·자전거도로·교량 기반시설 요약
- 학교·병원·문화시설·공원 현황 패널
- 공기질·유출 위험·열섬·탄소 지표 패널
- 시간과 날씨에 따라 바뀌는 도시 운영 이벤트

### 공간 탐색과 분석

- 광역·CBD·수변·산업·생태 구역 탐색
- 교통 혼잡, 열섬, 침수 위험 화면 분석 모드
- 지형·도로·건축·대중교통·녹지·행정구역·POI 레이어 UI
- 시드에 따라 재생성되는 미니맵
- 태블릿과 모바일 반응형 HUD

## 모듈 구조

```text
index.html
├── 기존 v0.3 생성·환경 제어
├── 시간·기후 시뮬레이션 제어
├── 분석 모드·구역 탐색
└── KPI·레이어·미니맵·분석 HUD

src/main.js
└── v0.3 WebGL 도시 생성·렌더링 엔진

src/simulation.js

src/simulation.css

```

## 다음 엔진 결합 단계

1. 차량을 정적 장식물이 아닌 도로 그래프 위 이동 에이전트로 전환
2. 경전철 차량 운행과 역별 승하차 수요 구현
3. 건물별 전력·수도·인구·일자리 상태 저장
4. 학교·병원·소방서의 서비스 권역 계산
5. 강우량과 지형·불투수면을 이용한 침수 셀 계산
6. 건물 밀도·녹지·기상에 따른 열섬 격자 생성
7. 실제 레이어별 메시 표시·숨김과 객체 선택
8. 건물·도로·시설 편집 및 변경 후 지표 재계산
9. 저장 가능한 도시 시뮬레이션 스냅샷
10. 장기적으로 Web Worker와 공간 타일 기반 LOD 도입

## 현재 한계

이번 커밋은 v0.3 엔진 위에 운영·환경 계층을 우선 연결한 단계다. 기상 효과와 분석 레이어는 화면 공간 표현이며, 다음 단계에서 실제 도로 그래프·건물 상태·수문 및 열환경 계산 결과와 직접 연결한다.
