# V4 검증 기록

## 자동 검증

`npm test`는 V3의 지형·도로·건축 회귀검사와 V4 연속 엔진 검사를 함께 실행한다.

| 검사 | 판정 기준 |
|---|---|
| 결정론 | 같은 시드로 240개월을 한 번에 진행한 결과와 12개월씩 20회 진행한 결과가 완전히 동일 |
| 무제한 시간 | 장기 시나리오가 300년까지 진행되고 `years === 300`; 120년 상수 없음 |
| 국가 위상 | 국가 12개, 중복 없는 양자관계 66개 |
| 인구 보존 | 세계 인구가 국가 인구 합과 반올림 오차 범위 내 동일 |
| 무역 보존 | 전체 수출액 = 전체 수입액 = 66개 양자 교역 합 |
| 이주 보존 | 전체 국제이주 유입 = 전체 국제이주 유출 |
| 범위 | 국가·도시 핵심 숫자가 유한하며 확률·안보 지표가 0–1 범위 |
| 도시 발생 | 42명·15동·3개 도로에서 시작해 인구·건축·도로가 내생적으로 증가 |
| 상호작용 | 통상·동맹·위기·제재·분쟁 중 하나 이상의 사건이 내생적으로 발생 |
| 메모리 | 최근 월별 기록은 최대 361개, 오래된 연사는 적응형 체크포인트 |
| 오프라인 계약 | V4 HTML, 로컬 Three.js, `현재` 버튼, 국가 선택, 관계 목록, CDN 없음 |

기준 장기검사는 300년 뒤에도 모든 보존식과 범위 검사를 통과했다. 1000년 별도 스트레스 실행에서도 NaN/Infinity 없이 완료되며, 오래된 월별 기록은 제거되고 적응형 체크포인트만 유지됐다.

## 회귀 유지

- 정착지 도로 39개, 필지 319개, 교량 2개
- 도로의 지형 추종, 수공간 회피, 교량 판정
- 건축 원형과 PBR 구성요소
- 로컬 고정 버전 Three.js 0.185.1

## 브라우저 검증 체크리스트

- 초기 로딩 화면이 사라지고 WebGL 장면이 표시됨
- 재생 후 시간축 최대값과 `현재` 연도가 계속 증가함
- 과거로 스크럽해도 미래를 자동 생성하지 않음
- `현재`를 누르면 생성된 최신 월로 돌아옴
- 세계 전환 시 관계선·흐름 입자·수도·정착지 표식이 표시됨
- 수도 또는 선택 목록으로 국가를 바꾸면 3D 강조와 모든 상대국 목록이 함께 갱신됨
- 통상·동맹·긴장·제재·분쟁 상태 색이 범례와 일치함
- 모바일에서 상단 정보, 국가 칩, 하단 시간축이 3D 화면을 과도하게 가리지 않음
- 콘솔 오류와 리소스 404가 없음

## 알려진 경계

- 합성 지형과 합성 국가이므로 실제 지명·국경·법·제도를 예측하지 않는다.
- 오래된 비체크포인트 월은 직전 장기 체크포인트의 사회 지표로 근사한다.
- 도로 후보망은 물리 지형에서 먼저 생성하고, 실제 개통 여부와 시기는 수요·재정이 결정한다.
- 브라우저 실시간성을 위해 기업·가구를 개별 객체가 아닌 코호트와 재고로 집계한다.
