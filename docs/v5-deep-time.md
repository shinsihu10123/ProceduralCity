# V5 심층 역사·단일 세계 설계

## 1. 목표

V5는 현대 도시와 국가를 초기조건으로 두지 않는다. 관측은 기원전 12,000년에 시작하지만 농경·국가·산업 기술의 출현 연도는 고정하지 않는다. 초기 상태는 이동형 수렵·채집 집단 8개, 약 400명, 불·석기·복합 수렵채집 지식뿐이다.

시뮬레이션이 설명해야 하는 질문은 다음과 같다.

1. 어떤 집단이 왜 이동하고 어디에 정착하는가?
2. 농경과 기술은 왜 어떤 문화권에서 먼저 채택되는가?
3. 정착지와 교통망은 어떻게 서로 강화되는가?
4. 정치체와 국경은 어떤 조건에서 생기고 변하는가?
5. 교역·이주·전쟁의 물리적 이동은 같은 지형 위에서 어떻게 나타나는가?

## 2. 물리 세계

`createPrimitiveWorld()`는 2,400km급 하나의 연속 공간을 만든다. V3의 판 구조 기반 고도 생성기를 사용하되 미리 생성된 국가·국경·수도는 모두 제거한다.

물리 래스터에는 다음 값이 있다.

- 고도, 경사 대용값, 해양까지 거리
- 기온, 강수, 생물군계, 거주 적합성
- 하류 셀, 유량 누적, 하천 강도
- 경작 적합성, 야생 식량, 목재, 석재
- 구리, 주석, 철, 석탄, 석유의 공간 분포

USGS의 수문 파생 자료 체계처럼 고도·유향·유량 누적·경사·집수 개념을 분리해 사용한다. [USGS HDMA](https://www.usgs.gov/data/hydrologic-derivatives-modeling-and-applications-hdma-data)

렌더링 좌표는 1 단위 = 100m다. 대륙, 생활권, 건물, 이동체가 같은 좌표계에 있으며 별도 지도나 순간이동 화면을 사용하지 않는다.

## 3. 인구와 생계

각 공동체는 다음 재고와 상태를 가진다.

- 인구, 출생, 사망
- 식량과 5개 비식량 재고
- 영양, 건강, 스트레스, 잉여, 부
- 이동/정착 여부, 건축물, 방어시설
- 문화권, 정치체, 생활권 좌표

수렵·채집 수용력은 야생 식량과 수원에 의해 제한된다. 식량 압력이 높아지면 이동하고, 집단이 커지면 분화한다. 풍부한 수원과 저장 기술이 축적되면 반정착·상설 정착으로 전환할 수 있다. 초기 마을을 수십~수백 명 규모로 두는 것은 최초 마을 사회에 관한 고고학 연구의 범위와 일치한다. [PNAS: Mobility and kinship in the world's first village societies](https://www.pnas.org/doi/10.1073/pnas.2209480119)

농경 채택 뒤에는 경작 적합성, 가축 사육, 금속 도구, 수송망에 따라 수용력이 증가한다. 인구가 수용력에 접근하면 초과 사망, 영양 악화, 이주와 신설 정착 압력이 높아진다.

## 4. 기술은 날짜가 아니라 조건으로 발생한다

기술은 32단계의 의존 그래프다. 모든 문화권은 불·석기·수렵채집에서 시작한다. 각 기술의 진전은 다음 항목의 곱으로 계산한다.

```text
연구 진전 = 인구 규모 × 식량 잉여 × 문화 접촉 × 기존 지식
           × 지역 자원 적합성 ÷ 기술 난도 ÷ 동시 연구 분산
```

교역로로 연결된 문화권은 기술 진행도의 일부를 서로 전달한다. 따라서 농경 확산은 사람의 이동과 인접 집단의 모방이 함께 작동하는 demic–cultural 혼합 과정이다. [Nature Communications: Modeling the European Neolithic expansion](https://www.nature.com/articles/s41467-025-63172-0)

기술 예시는 다음과 같다.

```text
석기 → 목재 가공 → 반정착 → 농경·토기·가축
농경·목재 → 바퀴·항해
토기·광물 → 구리 → 청동 / 철
농경·토기 → 문자 → 행정 → 도로·화폐
종이 → 인쇄 → 증기 → 철도·전기 → 통신·계산
```

자원이 없는 지역도 교역으로 접근할 수 있지만 진전 속도가 크게 느려진다. 특정 연도에 자동 해금되는 규칙은 없다.

## 5. 정착지–교통망 공동 진화

두 생활권의 연결 가능성은 인구 상호작용과 시대별 이동 범위로 평가한다. 실제 경로는 8방향 래스터 A* 최소비용 경로이며 비용에는 거리, 경사, 산악·습지·밀림·사막 저항, 하천 이동 이점, 항해 가능 여부가 포함된다.

반복 이동이 생기면 오솔길이 형성되고 교통량과 유지 투자가 쌓이면 수레길, 포장도로, 철도, 자동차도로로 승격된다. 반대로 교통이 적으면 상태가 악화된다. 이는 지형–교통–인구의 상호강화 모델을 따른다. [Scientific Reports: A model for simulating emergent patterns of cities and roads on real-world landscapes](https://www.nature.com/articles/s41598-022-13758-1)

## 6. 물류·교통·이주

생활권은 매년 식량·목재·석재·금속·수공품·연료를 생산해 재고에 넣는다. 연결된 생활권 사이에서 수출 가능 재고와 수입 부족분이 실제로 차감·가산된다.

- 노란색/재화색 이동체: 품목별 물류
- 밝은 이동체: 생활권 간 여행과 지역 교통
- 파란색 집단: 영양·부·스트레스 격차에 따른 이주
- 수레·선박·철도·자동차 표현: 경로의 기술 상태

화면의 이동체 수는 전체 사람과 화물을 1:1로 복제하지 않는다. 흐름량을 대표 표본으로 시각화해 대규모 장기 시뮬레이션의 성능을 유지한다.

## 7. 정치체와 국가 형성

상설 정착지, 농경 잉여, 공동 방어와 재분배가 일정 규모를 넘을 때 추장사회가 형성된다. 인구, 정착지 수, 문자, 행정, 인쇄·통신 수준에 따라 복합 추장사회, 초기국가, 도시국가, 왕국, 제국, 현대국가로 구조가 바뀐다.

정치 복잡성은 기술 하나로 결정하지 않고 인구 규모, 사회 조직, 정보 처리, 전쟁과 경제의 결합 결과로 취급한다. [Science Advances: Disentangling the evolutionary drivers of social complexity](https://www.science.org/doi/10.1126/sciadv.abn3517)

국경은 미리 그린 다각형이 아니다. 각 정치체 소속 생활권의 인구와 거리를 이용한 공간 영향권에서 매 시점 다시 계산된다. 인구 이동, 신설 정착, 편입, 정복으로 국경이 변한다.

## 8. 외교·전쟁·전투

모든 정치체 쌍은 신뢰, 긴장, 경쟁 성향, 교역 의존, 전쟁 상태를 가진다. 긴장은 다음 요인에서 증가한다.

- 가까운 접경 생활권
- 낮은 식량 안보와 자원 압력
- 큰 군사력 격차와 경쟁 성향

교역 의존과 신뢰는 전쟁 확률을 낮춘다. 임계치를 넘더라도 전쟁은 확률 사건이므로 결과가 고정되지 않는다. 전쟁이 시작되면 군대는 공격국 수도에서 목표 생활권까지 최소비용 경로를 따라 이동한다. 전투는 군사 조직, 청동·철·화약·기계화·항공 기술, 방어시설, 보급 거리와 확률 충격으로 해결한다. 패배는 인구 손실, 건물 파괴, 스트레스, 영토 편입을 일으킬 수 있다.

기후 충격과 인구 압력이 치명적 폭력을 높일 수 있다는 고고학 결과를 갈등 압력에 반영했다. [PNAS: Climate change–induced population pressure drives high rates of lethal violence](https://www.pnas.org/doi/10.1073/pnas.2117556119)

## 9. 한 장면의 시각 계층

| 상태 | 3D 표현 |
|---|---|
| 이동 야영지 | 천막·원형 초가와 황색 불빛 표식 |
| 정착·도시화 | 초가→목조/조적→고층 건물의 재질·형태 변화 |
| 건설 | 성장 중인 생활권의 비계 |
| 도로 | 오솔길·수레길·포장도로·철도·해상항로 폭과 재질 |
| 물류 | 품목 색상의 운송 단위가 실제 경로를 이동 |
| 교통 | 생활권 내부 순환과 생활권 간 이동체 |
| 이주 | 파란 집단이 출발지에서 목적지로 이동 |
| 국가 | 내생 영향권 국경과 수도 표식 |
| 군사 | 붉은 군대가 작전 경로의 현재 진척 위치에 표시 |
| 전투 | 전투 위치의 충돌 파동과 연기 |

카메라의 `대륙 / 권역 / 생활권`은 같은 장면의 거리만 변경한다. 지형 또는 모델을 교체하지 않는다.

## 10. 무제한 역사와 메모리

종료 연도는 없다. 최근 상태는 매년 생성하지만 장기 되감기용 체크포인트는 다음처럼 적응적으로 저장한다.

- 0~250년: 매년
- 250~2,500년: 10년 간격
- 2,500~10,000년: 50년 간격
- 10,000~50,000년: 100년 간격
- 이후: 500년 간격

시간축은 생성된 체크포인트만 보여 주며 미래 상태를 미리 계산하지 않는다.

## 11. 한계

- 세계는 실제 지구 DEM이 아니라 수문·판 구조 규칙으로 만든 합성 대륙이다.
- 개인 1명 단위가 아니라 생활권 단위 인구·재고 모델이다.
- 기술 그래프와 계수는 고고학적 메커니즘을 반영하지만 특정 실제 문명의 연대를 맞춘 보정 모형은 아니다.
- 건물·차량은 물리 스케일의 대표 표본이며 모든 사람과 화물의 1:1 복제가 아니다.
- 전염병, 종교, 법, 계층, 금융, 생태 천이 등은 현재 변수에 부분 반영되며 후속 세부 모듈로 확장할 수 있다.
