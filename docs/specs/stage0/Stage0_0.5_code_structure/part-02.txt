38. 공개 API 규칙
────────────────────────────────────────

38.1 공개 API 위치

모듈 외부 사용 가능 타입은 api/에만 둔다.

38.2 내부 타입 노출 금지

다음은 공개 API에 노출하지 않는다.
- 내부 가변 컬렉션
- 외부 엔진 타입
- 데이터베이스 구현 타입
- 스레드 primitive
- 내부 직렬화 구조
- 디버그 전용 상태

38.3 공개 계약 종류

Query
- 읽기 전용
- 권위 상태 수정 금지
- 가능한 한 명시적 결과 타입

Command
- 행동 의도
- 성공 보장 없음
- issuer와 원인 포함

Event
- 이미 발생한 사실
- 불변
- 원인 연결

Snapshot
- 특정 틱의 읽기 모델
- 권위 상태가 아님

Port
- 외부 시스템 또는 다른 계층과의 추상 인터페이스

38.4 공개 API 변경

공개 API 변경은 Stage 0.4의 Level 1 이상 변경으로 처리한다.

39. 의존 허용표
────────────────────────────────────────

표기:
O = 직접 의존 허용
C = 계약(api/port)으로만 허용
X = 직접 의존 금지

행 → 열 방향으로 의존한다고 가정한다.

                    Platform Kernel Foundation Domain Observation Persistence Adapters Presentation
Platform                -       X       C        X        X          X          X          X
Kernel                   C       -       O        X        C          C          C          X
Foundation               X       X       -        X        X          C          C          X
Domain                   X       C       O        C        X          C          C          X
Observation              X       C       O        C        -          C          C          X
Persistence              C       C       O        C        C          -          C          X
Adapters                 O       C       O        C        C          C          -          X
Presentation             C       C       O        C        O          C          O          -

세부 해석:

Platform
- 도메인을 모름

Kernel
- Foundation 사용 가능
- Domain 구현을 모름
- Domain이 등록하는 계약만 처리

Foundation
- 어느 도메인에도 의존하지 않음

Domain
- Kernel 계약과 Foundation 원시 타입 사용
- 다른 Domain은 공개 계약으로만 접근
- Observation/Presentation 참조 금지

Observation
- Domain 공개 읽기 계약과 Event 사용
- Domain 상태 수정 금지

Persistence
- 각 모듈의 직렬화 Port 사용
- 내부 구조를 강제 해석하지 않음

Adapters
- 외부 구현을 프로젝트 Port에 연결

Presentation
- Observation과 Snapshot 소비
- 직접 상태 쓰기 금지
