# Stage 1.2 — Space System

Status: PASS candidate

## Decision

The authoritative world coordinate uses signed integer millimetres on three axes.

- `WorldPosition`: continuous-world position in millimetres
- `CellCoord`: deterministic fine spatial partition
- `RegionCoord`: coarser streaming and simulation partition
- `CellLocalPosition`: local offset inside a cell
- `SpatialGrid`: immutable partition specification
- `WorldBounds`: half-open axis-aligned bounds

The default contract is:

- 1 authoritative unit = 1 mm
- 1 cell edge = 1,000 mm
- 1 region edge = 64 cells

## Rationale

Integer coordinates avoid floating-point drift and platform-dependent partition results. Euclidean division and remainder are required so negative coordinates partition symmetrically and deterministically. Half-open bounds avoid double ownership of boundary points.

## Invariants

1. Cell and region mapping is deterministic for every signed coordinate.
2. Local cell components are always in `[0, cell_size_mm)`.
3. Negative coordinates use Euclidean, not truncating, division.
4. Distance-squared calculations are exact integer calculations.
5. Invalid zero-sized grids and non-positive bounds are rejected.
6. Terrain, topology, height fields, and generated content are outside Stage 1.2 and begin in Stage 1.3.
