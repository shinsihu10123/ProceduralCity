# Stage 1.4 — Deterministic Baseline Climate System

## Status

PASS candidate. This document records the accepted Stage 1.4 baseline-climate contract. Seasonal oscillation remains Stage 1.5.

## Scope

Stage 1.4 provides a stateless, deterministic annual-mean climate field derived from world coordinates and Stage 1.3 terrain output.

Included outputs:

- annual mean temperature in milli-Celsius
- annual precipitation in millimetres
- relative humidity in permille
- aridity index in permille
- latitude proxy in permille
- broad climate classification

## Authoritative rules

- All authoritative calculations use integer arithmetic.
- Identical terrain configuration, world seed, and coordinates produce identical climate samples.
- The latitude proxy is derived from absolute distance to a configurable equator and a non-zero `u64` pole distance.
- Mean temperature combines an equator-to-pole gradient with elevation lapse-rate cooling above sea level.
- Moisture availability is influenced by terrain continentality.
- A deterministic west-to-east reference moisture path provides the initial orographic precipitation and rain-shadow contrast.
- Ocean samples receive saturated baseline humidity.

## Climate classes

- Ice
- Tundra
- Boreal
- Temperate
- Subtropical
- Tropical
- Arid
- Alpine

These are broad annual-mean classes, not a complete Köppen implementation.

## Stage boundaries

Deferred from Stage 1.4:

- seasonal temperature and precipitation oscillation: Stage 1.5
- dynamic surface-water transport: Stage 1.6
- pressure fields and dynamic winds: Stage 1.7
- transient weather systems and storms: later atmospheric stages

## Validation

- deterministic repeated sampling

- elevation lapse-rate cooling
- documented humidity, aridity, and latitude ranges

- reachability of warm and polar climate classes
