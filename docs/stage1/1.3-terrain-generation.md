# Stage 1.3 — Deterministic Terrain Generation

Status: PASS candidate

## Decision

The authoritative terrain foundation is generated from integer world coordinates and a world seed. It does not store a precomputed finite map and does not use floating-point arithmetic in authoritative terrain, hydrology, or river-network calculations.

The system separates four layers:

1. terrain sampling and morphology,
2. chunk sampling and shared-boundary contracts,
3. hydrology analysis and depression correction,
4. global river-network extraction.

## Authoritative terrain contract

- Horizontal coordinates use signed integer millimetres.
- Equal seed, configuration, and coordinates produce equal terrain samples.
- Negative coordinates are supported.
- Terrain generation is independent of chunk generation order.
- The base field combines continentality, local relief, and directional ridges.
- Mountain contribution is gated by continentality so deep-ocean spikes are suppressed.
- Terrain classes are derived from elevation, sea level, depth, and local relief.

The default terrain configuration is:

- base wavelength: 256,000 mm,
- maximum amplitude: 120,000 mm,
- octave count: 5,
- sea level: 0 mm.

## Chunk contract

A terrain chunk stores `(edge_cells + 1)²` samples. Adjacent chunks therefore regenerate the same world-coordinate samples along their shared boundary. Boundary equality is exact; no seam welding or floating-point tolerance is used.

Invalid dimensions, zero spacing, coordinate overflow, and excessive chunk dimensions are rejected explicitly.

## Hydrology contract

Local hydrology initially uses deterministic D8 drainage. Priority-Flood creates a separate hydrology-only corrected elevation surface; original terrain heights remain unchanged.

Flat corrected surfaces receive a deterministic drainage-distance field. Flow always moves either to a lower corrected elevation or toward a smaller flat-distance value. This makes the corrected local flow graph acyclic and removes artificial internal sinks.

Adjacent chunks validate original and corrected shared boundaries before cross-chunk flow links are accepted. Loaded chunks are then merged into one global directed acyclic drainage graph. Global accumulation and basin assignment are independent of input chunk order.

## River network contract

Nodes at or above a configurable accumulated-flow threshold are compressed into river reaches between structural junctions.

The network exposes:

- sources,
- confluences,
- mouths or loaded-area outlets,
- continuous reaches across chunk boundaries,
- Strahler order,
- integer width and depth seed values.

Width and depth values are initial geometric inputs for later water simulation, not final hydraulic results.

## Quality gates

The automated quality suite covers eight seeds and verifies:

- deterministic regeneration,
- minimum local elevation variation,
- zero corrected internal sinks,
- global hydrology order independence,
- non-empty river networks,
- valid river dimensions and Strahler order,
- aggregate land/ocean presence,
- multiple observed terrain classes,
- no exact repetition among widely separated sample windows.

The repetition test is an exact-window regression gate. It does not claim to be a complete spectral or perceptual repetition detector.

## Soak and performance gates

The release soak gate processes an 8×8 chunk set and verifies:

- 64 generated chunks,
- deterministic forward and reverse input results,
- complete global-node coverage,
- zero corrected local sinks,
- non-empty connected river output.

The release performance gate processes 16 chunks containing 17,424 samples through terrain generation, depression filling, local hydrology, global hydrology, and river extraction.

Reference GitHub Actions measurement from run `30875283004`:

- terrain generation: 12.18 ms,
- depression filling: 1.49 ms,
- local hydrology: 2.20 ms,
- global hydrology: 25.05 ms,
- river extraction: 3.68 ms,
- total: 44.59 ms,
- throughput: 390,716 samples/s,
- estimated core working set: 766,656 bytes.

These measurements are observations from a shared runner, not portable hard guarantees. CI enforces structural validity and a conservative 30-second upper safety limit.

## Known limitations and deferred work

The following are intentionally deferred:

- physically based erosion and sediment transport,
- rainfall, evaporation, seasonal discharge, and groundwater,
- persistent lakes and dynamic water levels,
- hydraulic floodplain simulation,
- biome, soil, and climate coupling,
- planet-scale streaming and unloaded-basin continuation,
- visual mesh generation and viewer integration,
- advanced spectral and perceptual terrain-quality analysis.
