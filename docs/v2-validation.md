## 4. 통과 불변식

### 세계

- 동일 시드 결과 해시 일치
- 다른 시드 결과 해시 불일치
- 육지 비율 28~68%
- 국가 수 8~14
- 모든 국가의 양의 면적·인구·GDP
- 정착지의 양의 고도·유효 국가·적합도 0.45 초과
- 배수 보정면에서 하류 고도가 상류보다 높지 않음
- 자기 자신을 잇지 않는 비음수 교역 회랑

### 사회

- `기말 인구 = 기초 인구 + 출생 - 사망 + 순이동`
- 고용 ≤ 노동력
- 실업률·신뢰도·접근성·지지율은 0~1
- 점유 주택 ≤ 전체 주택
- 전력·물·하수·폐기물·배수 용량은 비음수
- 경제·정부 수치에 NaN/Infinity 없음
- 철거 모델이 없으므로 건설 재고는 단조 증가
- 민간·공공 개발 의사결정 이벤트 존재

### 렌더링

- 모든 정점은 9-float stride와 유한값
- 초기 취락은 완성 도시보다 적은 건물·도로·정점 사용
- 성장 후 활성 건물·도로·정점은 감소하지 않음
- 거시 세계 정점 50,000개 이상
- 기존 v1.1의 도로·건물·수문 회귀 통과

## 5. 현실성 감사 결과

### 통과

- 세계→국가→정착지→사회→건설의 원인 방향이 명시적이다.
- 도로·건물은 최종 장면을 처음부터 전부 표시하지 않는다.
- 주택 부족, 금리, 시공 능력과 정부 예산이 실제 건설을 제한한다.
- 인구 성장은 고정 곡선이 아니며 주택·고용·서비스·재해에 반응한다.
- 합성 국가와 합성 지형을 실제 지구 데이터로 표시하지 않는다.
- 사진 수준 PBR·정밀 수리·BIM 등 미구현 범위를 문서에 명시했다.

### 남은 위험

1. 국가 영토는 최단거리 기반이라 역사·언어·민족·전쟁의 경로의존성이 없다.
2. 초기 가구 표본과 행동 계수는 실제 지역 미시자료로 추정한 값이 아니다.
3. 장기 명목 물가·임대료는 단순 지수이므로 100년 후 절대 금액을 현실 통화로 해석하면 안 된다.
4. 100년 뒤 잠재 타일 상한을 넘는 건물은 집계되지만 새 3D 타일이 생성되지 않는다.
5. 도시의 일일 교통은 사회 엔진의 노동·도로 재고와 완전히 수요 배정되지 않았다.
6. 절차적 재질은 유리·콘크리트·금속·물·아스팔트를 구분하지만 사진 텍스처와 실시간 그림자가 없다.

## 6. 판정

v2.0 alpha는 `국가가 있는 넓은 세계에서 작은 마을이 사회 시스템의 결과로 성장하는 장면`의 실행 가능한 첫 통합판으로 통과한다. 다만 실제 지역의 예측이나 토목·정책 의사결정에 사용할 수 있는 보정 모델은 아니다. 다음 정식 단계의 통과 조건은 실제 데이터 입력, 다중 정착지 타일, 교통 수요 배정, 고급 PBR과 장기 관측자료 보정이다.
