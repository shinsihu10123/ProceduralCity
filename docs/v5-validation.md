# V5 검증 기록

## 자동 검증

`npm test`는 V3·V4 회귀 검사와 함께 다음 V5 조건을 확인한다.

- 시작 연도는 기원전 12,000년
- 초기 생활권 8개는 모두 이동형 수렵·채집 집단
- 초기 국가와 사전 국경은 0개
- 초기 기술은 불·석기·수렵채집 3개뿐
- 같은 시드의 연 단위/일괄 진행 결과 동일
- 이전 120년 제한을 넘어 9,000년 이상 진행
- 상설 정착지와 농경이 날짜 지정 없이 발생
- 복수의 정치체와 교통망이 내생적으로 발생
- 물류·교통·이주·군대 흐름이 실제 상태로 생성
- 전쟁과 전투 사건이 발생하고 인구·영토에 반영
- 모든 장기 재고와 비율이 유한값 유지
- 오래된 역사는 적응형 체크포인트로 제한
- HTML에 분할 지도 전환이 없고 V5 단일 장면만 연결
- 외부 CDN 없이 로컬 Three.js 사용

## 수동 브라우저 검증표

1. 시작 화면에 `후기 구석기 시대 · 기원전 12,000년`이 표시된다.
2. 국가 지표가 `없음`이고 여러 이동 야영지가 하나의 대륙에 보인다.
3. 재생 후 시간축의 현재 끝점이 계속 확장된다.
4. 시간축을 뒤로 이동하면 생성된 과거 상태로 되돌아간다.
5. `대륙 / 권역 / 생활권`이 화면을 교체하지 않고 같은 지형을 확대한다.
6. 생활권을 누르면 카메라 이동 없이 선택되며 상세 패널 정보가 바뀐다.
7. 도로를 따라 물류·교통·이주 표본이 움직인다.
8. 국가 발생 뒤 국경·수도·상호작용 목록이 나타난다.
9. 전쟁 시 붉은 군대가 목표 방향으로 이동하고 전투 위치에 파동·연기가 나타난다.
10. 1366×1024 및 390×844에서 가로 스크롤과 핵심 UI 겹침이 없다.

## 장기 안정성 기준

- 인구, 영양, 건강, 스트레스, 부, 정치 정당성, 응집력, 군사력에 `NaN`/`Infinity`가 없어야 한다.
- 식량·비식량 재고는 음수가 될 수 없다.
- 영양·건강·스트레스·신뢰·긴장은 0~1 범위다.
- 소멸한 생활권을 참조하는 노선과 국가 수도는 다음 갱신에서 제거된다.
- 과거 체크포인트는 저장 당시 경로·국경·생활권 상태를 유지한다.

## 시각적 성능 전략

- 2,400km 물리 공간에 로그 깊이 버퍼 사용
- 건물·나무·이동체는 인스턴싱
- 인구와 물동량은 대표 표본 개수로 변환
- 국경은 정치 구조 변경 또는 장기 간격에만 재계산
- 도로 메시도 노선/등급 변경 시에만 재구성
- 그림자는 생활권 근거리에서만 활성화

## 알려진 환경 제약

WebGL이 시스템 차원에서 비활성화된 자동화 브라우저에서는 3D 컨텍스트를 만들 수 없다. 이 경우 HTML·CSS·모듈 로드, 엔진 테스트와 배포 파일 무결성은 검증할 수 있지만 최종 GPU 화면은 WebGL 지원 브라우저에서 확인해야 한다.
