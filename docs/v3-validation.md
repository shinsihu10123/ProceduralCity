# V3 검증 기록

## 자동 검사

`npm test`는 다음 세 묶음을 순서대로 실행한다.

| 검사 | 확인 내용 | 기준 시드 결과 |
|---|---|---:|
| `test-v3-spatial.mjs` | 결정론, 도로 ID·등급·유한 좌표, 지형 관통, 무교량 수공간 침범, 필지 전면·경사 | 39개 도로, 319개 필지, 2개 교량 |
| `test-v3-simulation.mjs` | 121개 시점, 인구 흐름 회계, 건물·도로 재고 단조성, 기능 다양성, 최종 주택·고용·서비스 | 42명 → 10,635명, 172동 |
| `test-v3-contract.mjs` | V3 전용 진입점, 외부 CDN 부재, vendored Three.js, 세계 결정론 | 12개국, 3,600km, 교역 18개 |

## 실제 브라우저 검사

- 뷰포트: 1366×1024
- 렌더러: WebGL2 소프트웨어 경로에서도 부팅 완료
- 콘솔 오류·페이지 오류: 0
- 로딩 화면 종료: 확인
- 초기/60년/120년 직접 이동: 확인
- 세계/정착지 전환과 `aria-pressed`: 확인
- 도시 장면: 171 draw calls, 약 785,500 triangles
- 세계 장면: 27 draw calls, 약 66,502 triangles
- GPU 텍스처: 15개

이 수치는 장면 복잡도 기록이며 특정 기기에서의 FPS 보증은 아니다.

## 시각 검토 항목

- 초기 장면에서 42명 규모의 저층 취락과 흙길이 먼저 보이는가
- 중기 장면에서 교량·간선·중층 건축이 수요에 따라 추가되는가
- 최종 장면에서 고층이 특정 중심지에 모이고 농촌 저층이 모두 사라지지 않는가
- 도로가 지형을 뚫거나 수면 아래로 내려가지 않는가
- 지붕·창호·문·발코니·포디움·옥상설비가 가까운 시점에서 구분되는가
- 상시 UI가 3D 화면 대부분을 가리지 않는가
- 슬라이더로 초기와 최종 상태를 기다리지 않고 직접 볼 수 있는가

## 남은 검증 한계

- 헤드리스 검사 환경에는 한국어 글꼴이 없어 캡처에서 한글이 사각형으로 보일 수 있다. 실제 iOS/macOS/Windows의 시스템 한글 글꼴 경로는 CSS에 포함되어 있으나, 기기별 스크린샷 회귀 검사는 아직 없다.
- 소프트웨어 WebGL 경로의 장면 완전성은 확인했지만, 모바일 GPU별 프레임 시간·메모리·열 스로틀링은 계측하지 않았다.
- 합성 지형과 도시 규칙은 불변식 검사를 통과하지만, 실제 도시 통계·교통량·지가·에너지 사용량과의 통계적 검정은 아직 수행하지 않았다.
