# Economic Lab — Four-Country Agent Economy

경제에 집중한 별도 실험 프로젝트다. 목표는 거시지표를 직접 갱신하는 모델이 아니라, **개별 경제주체의 추론·계약·거래·신용·생산·회계에서 거시경제가 파생되는 4개국 Agent-Based Economy**를 만드는 것이다.

## 핵심 원칙

1. GDP, CPI, 실업률, 평균임금, 기업이익, 통화량은 가능한 한 미시 상태와 실제 거래에서 파생한다.
2. 가계·기업·은행은 서로 다른 정보·목표·오류 가능성을 가진다.
3. Agent의 추론은 틀릴 수 있다. Objective Economy와 Agent Belief를 분리한다.
4. AI는 Action Intent를 만든다. 실제 거래·대출·생산·지급은 Market / Settlement / Accounting Engine이 판정한다.
5. 화폐·재고·채권·채무·고정자산은 장부 없이 임의 증감시키지 않는다.
6. 은행대출은 **대출자산과 예금부채의 동시 생성**으로 구현한다.
7. 기업 생산은 노동만으로 완제품이 생기는 방식이 아니라, 산업별 투입재와 공급망 제약을 거친다.
8. 국가별 차이는 초기조건일 뿐 장기 산업구조와 성장경로를 고정하지 않는다.

국가별 산업·성장·위기·금융경로는 미시행동의 결과로 형성한다.

## L0 — Settlement + Double-Entry Accounting

### Settlement Ledger
- 가계·기업의 거래 가능한 예금계정
- 임금, 최종재, 기업간 투입재, 설비투자의 실제 결제
- 은행대출 승인 시 예금통화 증가
- 대출 원리금 상환 시 예금통화 감소
- `기초 통화 + 승인된 통화변동 = 현재 통화` 자동 검증

### General Ledger
- Entity별 자산 / 부채 / 자본 / 수익 / 비용
- 가계: 예금, 미수임금, 대출부채, 임금수익, 소비비용, 이자비용
- 기업: 예금, 투입재고, 완제품재고, 고정자산, 미지급임금, 대출부채, 매출, 매출원가, 이자비용
- 은행: 준비자산, 유가증권, 대출자산, 예금부채, 자기자본, 이자수익, 신용손실
- 월말 수익·비용을 Retained Earnings로 마감
- Entity별 `Assets = Liabilities + Equity` 검증

### Stock-Flow Consistency
- 고객 General Ledger 예금 = Settlement Ledger 예금
- **은행 예금부채 = 전체 고객 예금잔액**
- **은행 대출자산 = 전체 차주의 대출부채**
- 기업간 구매 후 구매자 투입재고 증가와 판매자 완제품재고 감소를 양면 회계로 기록
- 설비투자 시 구매자의 Fixed Assets 증가와 자본재 기업의 매출/COGS를 동시에 기록

## L1 — Agent

### Household Agent
- 소비·저축
- 구직·실업위험 인식
- 물가·소득 기대
- 유동성 부족 시 신용수요

### Firm Agent
- 가격·생산·고용
- 재고·현금흐름 판단
- 확장 / 방어 / 가격경쟁 / 유지 전략 비교
- 운전자금 부족 또는 확장 시 신용수요
- 산업별 투입재 수요
- 공급부족에 의한 생산제약
- 생산능력과 기대수요에 따른 설비투자

### Bank Agent
각 국가는 현재 1개의 상업은행 Agent로 시작한다.

은행은 대출 신청마다:

`차주 현금·소득·부채·연체`
→ `거시 스트레스`
→ `부도확률 추정`
→ `상환부담`
→ `대출 후 자기자본비율`
→ `승인/거절 + 위험조정 금리`

를 계산한다. 모형불확실성과 판단 노이즈 때문에 잘못된 신용판단도 가능하다.

## L2 — Markets

현재 구현:
- 노동시장
- 가계 최종재시장
- 신용시장
- **기업간 투입재시장**
- **자본재·설비투자시장**

가계는 소비재 기업만을 대상으로 최종재를 구매한다. 원재료·소재·자본재는 기업간 시장에서 거래된다.

## L3 — Industry / Supply Chain — v0.5

현재 각 국가의 기업은 네 산업으로 분화한다.

### 1. RESOURCE
- 생산물: `raw_material`
- 핵심 제약: 노동, 생산성, 자본스톡, 국가의 resourceBase
- 외부 중간투입재 없음

### 2. MATERIALS
- 생산물: `processed_material`
- 투입: `raw_material`
- 원재료를 확보하지 못하면 잠재 생산능력이 있어도 생산량이 제한됨

### 3. CAPITAL
- 생산물: `capital_good`
- 투입: `processed_material`
- 생산된 자본재는 다른 기업의 설비투자로 판매됨

### 4. CONSUMER
- 생산물: `consumer_good`
- 투입: `processed_material`
- 가계가 실제로 구매하는 최종재 산업

따라서 기본 생산사슬은:

`RESOURCE`
→ `raw_material`
→ `MATERIALS`
→ `processed_material`
→ `CAPITAL / CONSUMER`

으로 연결된다.

## 기업간 주문·결제

각 기업은 기대수요, 목표재고, 생산능력을 바탕으로 원하는 생산량을 정한다. 필요한 투입재가 부족하면 공급기업을 탐색하고 가격·생산성을 제한적으로 비교한 후 구매한다.

기업간 거래는:

`Buyer Intent`
→ `Supplier Search`
→ `Available Inventory / Budget Check`
→ `Settlement Ledger Transfer`
→ `Physical Inventory Transfer`
→ `Double-Entry Accounting`

순서로 처리한다.

공급자가 충분한 재고를 보유하지 않으면 주문 전체가 충족되지 않으며 `supplyShortage`가 남는다. 이 부족은 실제 생산량을 제한한다.

## 생산과 원가

기업의 생산능력은 노동, 생산성, 인적자본, 자본스톡에 의해 결정된다. RESOURCE 산업은 국가 자원기반도 영향을 받는다.

중간재 기업은 필요한 물리적 투입량 이상을 생산할 수 없다. 사용된 투입재의 장부가치는:

`Input Inventory`
→ `Finished Goods Inventory`

로 이동하고, 해당 월의 노동원가도 완제품재고에 자본화된다. 판매 시점에만 COGS로 비용화된다.

## 설비투자

확장전략을 선택했거나 생산능력 활용도가 높은 기업은 현금여력이 있을 때 CAPITAL 기업으로부터 자본재를 구매한다.

구매자:
- Fixed Assets 증가
- capitalStock 증가
- 예금 감소

판매자:
- 예금 증가
- Sales Revenue 증가
- Finished Inventory 감소
- COGS 발생

따라서 투자는 단순히 `생산성 +x%`를 직접 적용하는 함수가 아니라 실제 자본재 생산과 거래를 거친다.

## 기업 진입·퇴출

기업은 심각한 유동성·임금체불·신용스트레스가 여러 달 지속되면 시장에서 퇴출될 수 있다. 퇴출 시 직원은 실업상태가 된다.

현재 v0.5에서는 퇴출이 발생하면 동일 산업에 제한적으로 신규 진입기업이 만들어진다. 신규기업은 예금·재고 없이 시작하며 이후 노동시장과 신용시장을 통해 실제 운영자금을 확보해야 한다.

이는 완전한 창업·파산법 모델은 아니며 이후 정부·법·금융 단계에서 확장한다.

## GDP — 폐쇄경제 단계

중간재 매출을 그대로 합산하면 GDP가 중복계상되므로 v0.5부터 단순 기업매출 합계를 GDP로 사용하지 않는다.

현재 정부·국제부문이 아직 없는 폐쇄경제에서는 지출접근으로:

`GDP = Household Final Consumption + Gross Fixed Investment + Inventory Investment`

을 사용한다.

즉:

`GDP = C + I + ΔInventory`

이다. 정부가 추가되면 G, 국제경제가 추가되면 NX가 연결될 예정이다.

## 아직 단순화된 부분

- 산업은 현재 4개 대분류이며 세부 업종·다중 생산물은 아직 없다.
- 기업간 장기계약, 운송비, 배송지연, 에너지, 지역별 물류망은 아직 없다.
- 자본재의 감가상각·노후화는 아직 단순화되어 있다.
- 기업 퇴출 시 법적 파산·채권회수 절차는 아직 기본 수준이다.
- 국가당 상업은행은 아직 1개다.
- 정부·세금·복지·국채·중앙은행 정책은 아직 없다.
- 국제무역과 환율도 아직 없다.
