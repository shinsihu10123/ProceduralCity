# Economic Lab — Four-Country Agent Economy

경제에 집중한 4개국 Agent-Based Economy다. 거시지표를 직접 조작하지 않고 **가계·기업·은행·중앙은행·정부의 추론과 실제 생산·거래·계약·회계에서 국내경제와 국제경제가 파생**되도록 만든다.

현재 기준 버전은 **v0.8 — International Economy**다.

## 핵심 원칙

1. GDP, CPI, 실업률, 임금, 통화량, 민간부채, 공공부채, 재정수지, 정책금리, 주가, 환율, 수출입, 경상수지와 대외부채를 가능한 한 미시 상태와 실제 거래에서 파생한다.
2. 가계·기업·은행·정부·중앙은행은 서로 다른 정보·목표·편향·오류 가능성을 가진다.
3. Agent 추론은 틀릴 수 있다. Objective Economy와 Agent Belief를 분리한다.
4. AI는 행동·정책·자금공급 의도를 만든다. 실제 체결은 Market / Settlement / Accounting Engine이 판정한다.
5. 예금·준비금·대출·국채·재고·고정자산·주식·대외채권·대외채무를 장부 없이 임의 증감시키지 않는다.
6. 은행대출의 예금창조, 중앙은행 준비금창조, 국제 FX 결제를 서로 다른 메커니즘으로 구분한다.
7. 국제거래는 공통 세계계산단위 `WXU`로 대칭 검증하며 각 국가는 독립된 통화와 변동환율을 가진다.
8. 국가별 차이는 초기조건일 뿐 장기 산업구조·무역패턴·성장경로를 미리 지정하지 않는다.

## 4개 국가

- **AST 아스테라** — 중상 인적자본, 중간 자본, 보통 개방도
- **BRN 브리노르** — 큰 노동공급, 낮은 초기 자본, 높은 내수 비중
- **CYR 사이렌** — 작은 인구, 높은 금융접근성과 개방도
- **DRN 데렌** — 높은 자원기반, 중간 인적자본, 낮은 금융심도

각 국가에는 자체 가계·기업·상업은행·정부·중앙은행·통화가 존재한다.

## 구현 계층

### L0 — Settlement / Double-Entry / Stock-Flow

- 가계·기업·정부 예금 Settlement Ledger
- Entity별 General Ledger
- `Assets = Liabilities + Equity`
- 은행예금부채 ↔ 고객예금
- 은행대출자산 ↔ 차주 대출부채
- 정부 국채부채 ↔ 은행 정부증권
- 중앙은행 준비금부채 ↔ 상업은행 준비금
- 가계 주식장부 ↔ 실제 포트폴리오
- 대외채권·채무 ↔ 국제포지션 장부
- 해외대출자산 ↔ 해외차입부채

### L1 — Economic Agents

- Household Agent
- Firm Agent
- Commercial Bank Agent
- Government Agent
- Central Bank Agent

추론은 제한된 관찰, 기억·기대, 위험성향, 모형불확실성, 노이즈를 포함하며 잘못된 판단이 가능하다.

### L2 — Domestic Markets

- 노동시장
- 소비재시장
- 신용시장
- 기업간 투입재시장
- 자본재·설비투자시장
- 정부구매
- 국채
- 주식 1차·2차시장

### L3 — Industry / Supply Chain

기본 생산사슬:

`RESOURCE → raw_material → MATERIALS → processed_material → CAPITAL / CONSUMER`

기업은 실제 투입재를 확보하지 못하면 잠재 생산능력이 있어도 생산량이 제한된다. 자본재 구매는 Fixed Assets와 capitalStock을 증가시킨다.

## v0.8 — International Economy

### 독립 통화와 환율

각 국가는 자체 통화를 가진다.

- ASTC
- BRNC
- CYRC
- DRNC

`WXU`는 국가 간 거래가 양쪽에서 같은 경제가치인지 검증하기 위한 공통 세계계산단위다.

각 통화의 `Local Currency / WXU` 환율은 고정된 결과가 아니라 다음의 영향을 받는다.

- 직전 무역불균형
- 대외부채 압력
- 국가 간 정책금리 차이
- 이전 환율 모멘텀
- 시장 노이즈

따라서 환율판단과 시장 움직임은 틀릴 수 있고 과잉반응도 가능하다.

### 국제 공급망

국내 기업이 필요한 투입재를 충분히 확보하지 못하면 외국 공급자를 탐색할 수 있다.

`국내 공급부족`
→ `해외 공급자 탐색`
→ `현지가격 / 환율 / 관세 / 무역마찰 / 생산성 비교`
→ `주문`
→ `FX Settlement`
→ `물리적 재고 이동`
→ `양국 복식부기`

현재 국제거래 채널:

- 원재료·중간재 수입
- 자본재 수입
- 가계 소비재 수입

따라서 한 국가의 생산부족이나 가격변화가 다른 국가의 기업 생산과 소비에 영향을 줄 수 있다.

### 국제 FX Settlement

수입기업 또는 가계가 해외상품을 구매할 경우 단순히 두 국가 계정 사이를 같은 화폐로 이체하지 않는다.

수입국:

`수입자 예금 감소`
→ `수입국 은행 예금부채 감소`
→ `수입국 은행 대외지급채무 증가`

수출국:

`수출국 은행 대외수취채권 증가`
→ `수출기업 예금 증가`
→ `수출국 은행 예금부채 증가`

양쪽 거래가 `WXU` 기준으로 같은 값인지 세계 수준에서 검증한다.

### 관세

수입국은 자체 관세율을 가진다. 관세는 단순 가격 가중치가 아니라 실제로:

`수입자 예금 → 정부 국고예금`

으로 이전되며 정부의 Tax Revenue에 기록된다.

### 대외포지션

각 국가는 다음 Stock을 가진다.

- Foreign Settlement Receivables
- Foreign Settlement Payables
- Cross-Border Bank Loans
- Cross-Border Bank Borrowing

이를 통해:

- 순대외자산 NFA
- 대외부채
- 대외금융 스트레스
- 경상수지
- 금융계정 대응

을 계산한다.

### 해외자금조달 AI

대외지급채무가 누적된 국가의 은행은 다른 국가 은행으로부터 정식 해외자금을 조달할 수 있다.

대주은행은 다음을 불완전하게 판단한다.

`차입국 대외부채`
+ `경상수지 압력`
+ `환율절하`
+ `차입은행 자본비율`
+ `대주은행 자본여력`
→ `예상 부도확률`
→ `해외자금 승인/거절`
→ `위험조정 금리`

승인 시 단기 결제채권·채무가 정식 `foreign_loans / foreign_borrowing` 계약으로 재분류된다. 원금과 이자 상환은 이후 다시 국제 결제포지션에 반영된다.

## 개방경제 GDP

v0.8부터 지출접근 GDP는:

`GDP = C + I_private + I_public + G + ΔInventory + X - M`

이다.

수입 소비재는 가계소비 `C`에 포함되지만 동시에 `M`으로 차감되고, 수입 자본재도 투자 `I`와 수입 `M`에 동시에 반영된다. 중간재 수입은 최종지출에 직접 더하지 않고 생산·재고·원가를 통해 결과에 반영된다.

## 세계 수준 불변식

v0.8 CI는 다음을 자동 검증한다.

- 세계 총수출 `= 세계 총수입` (`WXU`)
- 4개국 경상수지 합 `= 0`
- 4개국 순대외자산 합 `= 0`
- 해외대출자산 합 `= 해외차입부채 합`
- 각국 은행 대외채권 장부 `= International Position`
- 각국 은행 대외채무 장부 `= International Position`
- 기존 국내 Settlement / SFC / A=L+E 불변식 유지

## v0.8에서 발견·수정된 기존 금융 경계조건

국제거래가 일부 기업의 유동성을 낮추면서 기존 민간대출 상환 코드의 연체 경계조건이 드러났다. 과거 구현은 연체 catch-up 금액을 Settlement 상환액에 추가하면서도 일부 경우 남은 원금보다 많은 현금을 소멸시킬 수 있었다.

수정 후:

`실제 상환액 ≤ 남은 원금 + 당월 이자`

를 보장하고, Settlement에서 소멸한 예금과 차주·은행 GL에 기록된 원금·이자가 정확히 일치한다.

## 현재 단순화된 부분

- 세계통화시장에는 아직 딜러·주문장 기반 FX microstructure가 없다.
- 국제결제는 현재 은행 간 청산포지션 방식이며 외환보유액·국제준비자산은 다음 확장 대상이다.
- 국제무역에 명시적 운송시간·선박·보험·항만·지역 물류망은 아직 없다.
- 무역협정·쿼터·제재·자본통제는 아직 없다.
- 국가당 상업은행은 현재 1개다.
- 세부 업종과 다중 생산물 체계는 후속 확장 대상이다.
