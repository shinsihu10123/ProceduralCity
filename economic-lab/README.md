# Economic Lab — Four-Country Agent Economy

경제에 집중한 별도 실험 프로젝트다. 목표는 거시지표를 직접 갱신하는 모델이 아니라, **개별 경제주체의 추론·계약·거래·신용·회계에서 거시경제가 파생되는 4개국 Agent-Based Economy**를 만드는 것이다.

## 핵심 원칙

1. GDP, CPI, 실업률, 평균임금, 기업이익, 통화량은 가능한 한 미시 상태와 거래에서 파생한다.
2. 가계·기업·은행은 서로 다른 정보·목표·오류 가능성을 가진다.
3. Agent의 추론은 틀릴 수 있다. Objective Economy와 Agent Belief를 분리한다.
4. AI는 Action Intent를 만든다. 실제 거래·대출·상환은 Market / Settlement / Accounting Engine이 판정한다.
5. 화폐·재고·채권·채무는 장부 없이 직접 바꾸지 않는다.
6. 은행대출은 단순 기존 돈의 이전이 아니라 **대출자산과 예금부채의 동시 생성**으로 구현한다.
7. 국가별 차이는 초기조건일 뿐 장기 역할은 고정하지 않는다.

## 4개 국가

| ID | 국가명 | 초기 특징 |
|---|---|---|
| AST | 아스테라 | 중상 인적자본, 중간 자본, 보통 개방도 |
| BRN | 브리노르 | 큰 노동공급, 낮은 초기 자본, 높은 내수 비중 |

국가별 산업·성장·위기·금융경로는 미시행동의 결과로 형성한다.

## L0 — Settlement + Double-Entry Accounting

### Settlement Ledger
- 가계·기업의 거래 가능한 예금계정
- 임금과 상품구매의 실제 결제
- 은행대출 승인 시 예금통화 증가
- 대출 원리금 상환 시 예금통화 감소
- `기초 통화 + 승인된 통화변동 = 현재 통화` 자동 검증

### General Ledger
- Entity별 자산 / 부채 / 자본 / 수익 / 비용
- 가계: 예금, 미수임금, 대출부채, 임금수익, 소비비용, 이자비용
- 기업: 예금, 재고, 미지급임금, 대출부채, 매출, 매출원가, 이자비용
- 은행: 준비자산, 유가증권, 대출자산, 예금부채, 자기자본, 이자수익, 신용손실
- 월말 수익·비용을 Retained Earnings로 마감
- Entity별 `Assets = Liabilities + Equity` 검증

### Stock-Flow Consistency 검증
- 고객 General Ledger 예금 = Settlement Ledger 예금
- **은행 예금부채 = 전체 고객 예금잔액**
- **은행 대출자산 = 전체 차주의 대출부채**
- 대출생성·상환·부도 이후에도 위 관계를 자동 검사

## L1 — Agent

### Household Agent
- 소비·저축
- 구직·실업위험 인식
- 물가·소득 기대
- 유동성 부족 시 신용수요

### Firm Agent
- 가격·생산·고용
- 재고·현금흐름 판단
- 확장 / 방어 / 가격경쟁 / 유지 전략 비교
- 운전자금 부족 또는 확장 시 신용수요

### Bank Agent — v0.4
현재 각 국가는 1개의 상업은행 Agent로 시작한다. 다은행 경쟁과 은행간 결제는 후속 금융시장 단계에서 확장한다.

은행은 대출 신청마다 다음을 추론한다.

`차주 현금·소득·부채·연체`
→ `거시 스트레스 인식`
→ `부도확률 추정`
→ `상환부담 추정`
→ `대출 후 자기자본비율 예상`
→ `위험한도·자본제약 비교`
→ `승인/거절 + 위험조정 금리`

은행의 추정은 노이즈와 모형불확실성을 포함하므로 틀릴 수 있다.

## L2 — Markets

현재 구현:
- 상품시장
- 노동시장
- **신용시장**

신용시장에서는:
- 가계·기업이 실제 대출 신청
- 은행 AI가 신청별 승인/거절
- 승인 시 Loan Contract 생성
- 월별 원금·이자 상환
- 현금 부족 시 미납·연체 누적
- 반복 연체 시 부도 및 은행 대출상각

## 내생적 화폐창조

대출 승인 시:

**차주**
- DR Bank Deposit
- CR Loan Payable

**은행**
- DR Loan Asset
- CR Customer Deposit Liability

동시에 Settlement Ledger의 해당 차주 예금잔액이 증가한다.

대출 상환 시 차주의 예금이 감소하며 은행의 예금부채와 대출자산도 같이 감소한다. 이자 지급분은 은행의 이자수익으로 전환된다.

따라서 v0.4부터 통화량은 더 이상 고정값이 아니다.
