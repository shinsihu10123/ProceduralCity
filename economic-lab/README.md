# Economic Lab — Four-Country Agent Economy

경제에 집중한 별도 실험 프로젝트다. 목표는 거시지표를 직접 조작하는 모델이 아니라, **가계·기업·은행·정부의 추론, 계약, 생산, 거래, 신용, 조세, 지출과 회계에서 거시경제가 파생되는 4개국 Agent-Based Economy**를 만드는 것이다.

현재 기준 버전은 **v0.6 — Government & Fiscal System**이다.

## 핵심 원칙

1. GDP, CPI, 실업률, 임금, 통화량, 민간부채, 공공부채와 재정수지는 가능한 한 미시 상태와 실제 거래에서 파생한다.
2. 가계·기업·은행·정부는 서로 다른 정보·목표·편향·오류 가능성을 가진다.
3. Agent의 추론은 틀릴 수 있다. Objective Economy와 Agent Belief를 분리한다.
4. AI는 Action Intent와 정책 의도를 만든다. 실제 거래·지급·대출·세금·국채는 Settlement / Market / Accounting Engine이 판정한다.
5. 예금·재고·채권·채무·고정자산·공공자본을 장부 없이 임의 증감시키지 않는다.
6. 은행대출과 은행의 국채매입은 대차대조표 양면을 동시에 생성한다.
7. 기업 생산은 실제 산업별 투입재와 공급망 제약을 거친다.
8. 국가별 차이는 초기조건일 뿐 장기 결과를 미리 지정하지 않는다.

## 경제 계층

### L0 — Settlement + Double-Entry Accounting

Settlement Ledger는 실제 예금 이동과 통화 생성·소멸을 기록한다.

현재 실제 결제 종류:
- 임금
- 가계 최종재 구매
- 기업간 원재료·중간재 구매
- 민간 설비투자
- 민간대출 생성·상환
- 소득세·소비세·법인세
- 실업·사회이전
- 정부 최종소비
- 공공투자
- 국채 발행·원리금 상환

General Ledger는 각 Entity의 자산·부채·자본·수익·비용을 복식부기로 기록한다.

주요 자동 검증:
- Entity별 `Assets = Liabilities + Equity`
- GL 예금 ↔ Settlement 예금
- 은행 예금부채 ↔ 전체 Settlement 예금
- 은행 민간대출자산 ↔ 가계·기업 대출부채
- 정부 국채부채 ↔ 실제 국채계약 잔액
- 은행의 정부증권 증가분 ↔ 정부 국채잔액
- `기초예금 + 승인된 통화변동 = 현재 예금통화`

## L1 — Economic Agents

### Household Agent
- 소비·저축
- 구직과 실업위험 인식
- 물가·소득 기대
- 대출수요
- 세후·이전 후 가처분소득을 기반으로 소비 결정

### Firm Agent
- 가격·생산·고용
- 확장 / 방어 / 가격경쟁 / 유지 전략 비교
- 운전자금·설비투자 신용수요
- 투입재 조달
- 공급부족 대응
- 실제 자본재 투자
- 유동성 악화 시 퇴출 가능

### Bank Agent
- 차주 유동성·부채·연체·거시상황 관찰
- 부도확률과 상환부담 추정
- 대출 후 자기자본비율 예상
- 승인/거절 및 위험조정 금리 결정
- 판단 노이즈와 모형불확실성으로 오판 가능

### Government Agent — v0.6

정부는 실업률·인플레이션·공공부채·직전 재정수지를 제한적으로 관찰하고 세 가지 정책기조를 비교한다.

`확장 / 중립 / 재정건전화`

정부마다 다음 성향이 다르다.
- 성장선호
- 부채회피
- 자동안정화 강도
- 낙관/비관 편향
- 정책모형 불확실성

정책판단 결과로 다음이 조정된다.
- 소득세율
- 소비세율
- 법인세율
- 실업급여 대체율
- 정부 최종소비 목표
- 공공투자 목표

정부의 판단 역시 틀릴 수 있다.

## L2 — Markets / Fiscal Flows

현재 구현:
- 노동시장
- 가계 최종재시장
- 민간 신용시장
- 기업간 투입재시장
- 자본재·설비투자시장
- 조세·이전지출 흐름
- 정부 최종재 조달
- 국채·재정금융 흐름

## L3 — Industry / Supply Chain

각 국가는 현재 네 산업을 가진다.

`RESOURCE → raw_material → MATERIALS → processed_material → CAPITAL / CONSUMER`

- RESOURCE: 원재료 생산
- MATERIALS: 원재료를 가공해 소재 생산
- CAPITAL: 소재를 사용해 자본재 생산
- CONSUMER: 소재를 사용해 가계·정부용 최종소비재 생산

투입재가 부족하면 잠재 생산능력이 있어도 실제 생산량이 제한된다. 기업간 거래는 실제 예금이 이동하고 구매자의 Input Inventory와 판매자의 매출·COGS가 동시에 기록된다.

민간 설비투자는 CAPITAL 기업이 실제 생산한 자본재를 구매해야 발생하며 구매기업의 Fixed Assets와 물리적 capitalStock을 증가시킨다.

## L4 — Government / Fiscal Economy — v0.6

### 조세

**소득세**
- 실제 지급된 가계 임금을 과세기반으로 사용
- 임금 대비 완만한 누진성을 적용
- 가계 예금 → 국고예금으로 실제 결제

**소비세**
- 실제 가계 최종소비를 과세기반으로 사용
- 가계 예금 → 국고예금

**법인세**
- 해당 월 기업 General Ledger의 양(+)의 세전이익을 과세기반으로 사용
- 기업 예금 → 국고예금

### 자동안정화장치

실업 가계에 평균임금과 정부가 선택한 급여대체율을 이용해 이전지출을 지급한다.

`실업 증가 → 이전지출 대상 증가 → 가계 가처분소득 보전 → 소비행동에 반영`

정부가 현금을 충분히 보유하지 못하면 재원조달 가능성에 따라 국채를 발행한다.

### 정부 최종소비

정부는 CONSUMER 기업의 실제 완제품재고를 구매한다. 따라서 정부수요와 민간수요는 동일한 희소한 최종재를 두고 경쟁하며, 정부지출을 단순히 GDP 숫자에 더하지 않는다.

### 공공투자

정부는 CAPITAL 기업의 실제 자본재를 구매한다.

정부:
- Treasury Deposit 감소
- Public Capital 증가

자본재기업:
- Deposit 증가
- Sales Revenue 발생
- Finished Inventory 감소
- COGS 발생

현재 공공자본은 자산 스톡으로 추적되며 생산성에 미치는 세부 효과는 후속 단계에서 별도 인과경로로 추가한다.

## 공공부채와 국채

각 국가는 역사적 초기조건을 표현하기 위해 **0이 아닌 초기 공공부채와 국고예금 스톡**으로 시작한다. 이는 임의 숫자 추가가 아니라 은행의 국채매입을 통해 양면 기록된다.

국채 발행 시:

**정부**
- DR Treasury Deposit
- CR Government Bonds Payable

**은행**
- DR Securities
- CR Customer Deposits

Settlement Ledger에서는 정부 예금이 증가한다.

국채 원리금 상환 시 정부 예금이 소멸하고:
- 원금은 정부 Bonds Payable과 은행 Securities를 동시에 감소
- 이자는 정부 Interest Expense와 은행 Interest Income으로 기록

은행의 자기자본 제약 때문에 정부가 원하는 만큼 무제한 발행할 수는 없다.

## GDP — v0.6

중간재 거래를 GDP에 중복계상하지 않는다. 국제부문이 아직 없는 현재 단계에서는 지출접근으로:

`GDP = C + Private I + Public I + Government Consumption + ΔInventory`

을 사용한다.

정부의 이전지출은 최종재 구매가 아니므로 G에 직접 포함되지 않는다. 이전지출이 가계소득과 소비행동을 변화시킨 결과만 최종수요에 나타난다.

국제경제 단계에서 `NX`가 추가된다.
