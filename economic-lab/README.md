# Economic Lab — Four-Country Agent Economy

경제에 집중한 4개국 Agent-Based Economy다. 거시지표를 직접 조작하지 않고 **가계·기업·은행·중앙은행·정부의 추론과 실제 거래·계약·회계**에서 GDP, 물가, 실업, 신용, 재정, 통화·금융조건이 파생되도록 만든다.

현재 기준 버전은 **v0.7 — Central Bank & Financial Markets**다.

## 핵심 원칙

1. GDP, CPI, 실업률, 임금, 통화량, 민간부채, 공공부채, 재정수지, 금융조건은 미시 상태와 실제 거래에서 파생한다.
2. 가계·기업·은행·정부·중앙은행은 서로 다른 정보·목표·편향·오류 가능성을 가진다.
3. Agent 추론은 틀릴 수 있다. Objective Economy와 Agent Belief를 분리한다.
4. AI는 행동·정책 의도를 만든다. 실제 체결은 Market / Settlement / Accounting Engine이 판정한다.
5. 예금·준비금·대출·국채·재고·고정자산·주식을 장부 없이 임의 증감시키지 않는다.
6. 은행대출의 예금창조와 중앙은행 준비금창조를 구분한다.
7. 공개시장조작과 중앙은행 대출은 상업은행 준비금을 바꾸지만 민간 예금통화를 직접 바꾸지 않는다.
8. 국가별 차이는 초기조건일 뿐 장기 결과를 미리 지정하지 않는다.

## 4개 국가

- AST 아스테라
- BRN 브리노르
- CYR 사이렌
- DRN 데렌

각 국가는 가계·기업·상업은행·정부·중앙은행을 가지며 산업구조와 금융경로는 시뮬레이션 결과로 변화한다.

## 중앙은행 Agent — v0.7

중앙은행은 다음 정보를 불완전하게 관찰한다.

`인플레이션 / 실업 / 신용경색 / 은행자본 / 준비금 / 자산가격 모멘텀`

이후 **완화 / 중립 / 긴축** 정책 후보의 효용을 비교하고 정책금리를 정한다. 모형불확실성과 관찰오차가 있으므로 잘못된 판단도 가능하다.

정책금리는:

`중앙은행 정책금리`
→ `상업은행 조달 기준금리`
→ `차주별 위험조정 대출금리`
→ `신용·투자·소비`

경로로 전달된다.

## 준비금·공개시장조작·최종대부자

상업은행의 예금부채가 증가하면 필요한 준비금도 증가한다. 실제 준비금이 목표보다 부족하면 중앙은행은:

1. 유가증권 공개시장매입
2. 남은 부족분에 대한 중앙은행 유동성대출

을 사용할 수 있다.

공개시장매입:

**상업은행**
- Reserves 증가
- Securities 감소

**중앙은행**
- Market Securities 증가
- Reserve Liability 증가

중앙은행 대출:

**상업은행**
- Reserves 증가
- Central Bank Borrowing 증가

**중앙은행**
- Lending to Banks 증가
- Reserve Liability 증가

따라서 준비금은 증가하지만 민간 Settlement Ledger 예금은 직접 증가하지 않는다.

자동 검증:

- 상업은행 준비금 = 중앙은행 Reserve Liability
- 상업은행 Central Bank Borrowing = 중앙은행 Lending to Banks
- 중앙은행 Assets = Liabilities + Equity

## 주식시장 — v0.7

기업은 현금부족·확장수요·높은 설비가동 등 자본수요가 있을 때 신주를 발행할 수 있다.

신주 인수 시:

`가계 예금 → 기업 예금`

가계 장부:
- Equity Investments 증가
- Cash 감소

기업 장부:
- Cash 증가
- Paid-in Capital 증가

따라서 주식발행은 매출이나 은행대출이 아니라 실제 자기자본조달이다.

가계 간 2차 주식거래도 가능하며 매입원가·실현손익을 별도 회계 처리한다.

주가는 현재 기업상태, 이익, 수요기대, 레버리지, 정책금리, 스트레스, 시장노이즈의 영향을 받아 움직인다. 중앙은행은 이 자산가격 흐름을 다음 정책판단의 정보로 사용한다.

자동 검증:

- 물리적 포트폴리오 장부가 = 가계 General Ledger Equity Investments
- 모델 내부 공개주식수 = 가계 보유주식 합계

## GDP

국제부문이 아직 없으므로 현재 GDP는 지출접근으로:

`GDP = C + Private I + Public I + G + ΔInventory`

를 사용한다. 중간재 매출과 주식거래는 GDP에 중복 포함하지 않는다.
