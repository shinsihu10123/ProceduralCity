Date: 2026-08-22

Mode: diagnostic causal ablation; not canonical repair

## Question

R4-AZ shows high same-month action concentration, especially among CONSUMER firms. R4-BC asks whether that concentration is materially generated by the v0.9/v0.10 cognitive decision layer itself, or whether it persists under the pre-cognitive legacy decision path because common macro conditions and structural constraints dominate.

## Base

Use the prior MATERIALS+CONSUMER diagnostic normalization and initialPrice≈initialWage transformation. This avoids reintroducing already-known nominal/unit-economics defects while preserving canonical accounting, markets, credit, payroll, fiscal policy, exit logic and transaction order.

## Factorial regimes

1. `control` — current cognitive firms + current cognitive households.
2. `legacy-firms` — firms use the existing legacy firm-decision code path; households remain cognitive.
3. `legacy-households` — households use the existing legacy household-decision code path; firms remain cognitive.
4. `legacy-both` — both firm and household populations use existing legacy decision paths.

No new behavioral coefficients are introduced. Entrant firms inherit the regime.

## Interpretation gates

- If `legacy-firms` materially reduces CONSUMER synchronization while macro collapse also weakens, the cognitive architecture becomes a supported amplification mechanism.
- If synchronization falls but collapse remains, cognitive synchronization is real but secondary.
- If synchronization remains high under legacy firms, common environment/structural constraints dominate the synchronization result.
- Household-only effects are interpreted separately from firm-side effects.
- A different macro trajectory does not by itself prove the legacy path is realistic.
