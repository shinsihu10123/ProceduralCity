# WP-RV08 R4-AR — Working-Age / Labor-Force Feasibility Sensitivity Audit

Date: 2026-08-22
Mode: diagnostic-only

## Purpose

R4-AQ confirmed that the current Economic Lab has no age/labor-force-participation/lifecycle structure and that all household agents are included in the unemployment denominator. R4-AR asks the next narrow question without inventing a demographic model:

**If only a fraction of the represented population were actually available to work, how often would economically viable physical labor need exceed that labor force?**

## Sensitivity shares

Labor-force availability shares:

- 0.40
- 0.50
- 0.60
- 0.70
- 0.80
- 0.90
- 1.00

These are sensitivity values only, not empirical demographic calibration.

## Measures

For each month/country:

- total household agents
- employed household agents
- all-firm physical worker need implied by unconstrained production plan
- economically viable physical worker need
- posted desired workers
- each of the above relative to the assumed labor-force envelope
- share of observations where physical/viable/posted labor demand exceeds the assumed labor force

## Compatibility

For comparability with R4-AP, R4-AR retains the same transformed initial price-wage unit basis and the same CONSUMER vs MATERIALS+CONSUMER productive-normalization diagnostic bases. The labor-force-share calculation itself never changes economic state.

## Matrix

- original A/C

- CONSUMER / MATERIALS+CONSUMER
- 24 months
- 8 independent shards

## Interpretation

- If viable physical labor need remains below a plausible labor-force envelope, demographics mainly affect measurement/realism rather than the current collapse root.
- If viable physical labor need repeatedly exceeds the envelope once nonparticipants are recognized, the current world has a population/labor-supply feasibility problem in addition to the already-established labor-target/payroll defect.
- Posted desired jobs remaining far below the labor-force envelope while physical need exceeds it would reinforce that the dominant current mechanism is target/payroll incoherence, with demographic scarcity becoming a latent constraint once that mechanism is repaired.

No canonical demographic or labor-market repair is authorized by R4-AR alone.
