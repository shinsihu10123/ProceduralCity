## Classification

### A — VERIFIED EXISTING FACT

Sector price/cost mismatches have causal effects, but those effects are transmitted through the supply chain. Correcting one sector's price can shift the loss burden into its buyers.

### B — DIAGNOSTIC LEAD

The strongest common explanation for P29-P33 is no longer 'a few prices are too low'. It is a mismatch between:

- physical output units per worker/capacity,
- wage obligations,
- intermediate input coefficients,
- and the industry's relative price/value structure.

RESOURCE is especially diagnostic because it has no upstream input requirement yet is deeply underwater from the first window. A price-only repair raises raw-material cost for every downstream sector.
