## v0.10 scope now implemented

### 1. Scale profiles and runtime instrumentation

`src/core/world-v10.js` extends the v0.9 cognitive economy with explicit scale profiles, runtime metrics, subsystem profiling, experiment scheduling, long-run health monitoring, emergence reporting, and compact decision-history policy.

The v0.10 world preserves the v0.9 objective-economy / agent-belief separation and accounting engine instead of replacing the economic model with a separate benchmark model.

### 2. Counterfactual experiment harness

`smoke-v10.mjs` verifies a paired control/treatment experiment using the same seed. The control and treatment histories must remain identical before the scheduled intervention and diverge only after the intervention is applied.

The current gate includes an AST productivity shock and confirms that the treatment changes the treated economy while accounting invariants remain valid.

### 3. Paired multi-seed ensemble

`smoke-v10-ensemble.mjs` runs paired experiments across multiple seeds, checks finite treatment effects, verifies the expected direction of the treated productivity effect, and requires the repeated ensemble digest to be deterministic for the same seed set and intervention.

### 4. Long-run health and emergence metrics

`smoke-v10.mjs` contains a 48-month compact-population long-run gate. It requires clean health records, finite timing data, finite emergence metrics, four-country coverage, and a valid v0.10 snapshot after the run.

The v0.10 research layer includes:
