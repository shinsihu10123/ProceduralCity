## Frozen acceptance basis

FINAL v2.1.3a defines S1.02.07 as the versioned `Cross-Reference Integrity Contract` over the operands `Cross-Reference`, `Integrity`, `Stable`, `Entity`, and `ID`. The contract reads the Frozen WHAT/HOW root, current cross-reference state/event/reference data, PA-003/D26 ownership, and the persistent identity boundary established by the preceding S1.02 members. It validates required fields, versions, owner, allowed state transitions and explicit forbidden paths. It may return a versioned validation result or an exact rejection reason, but it does not write Canonical State itself.

Required test classes are behavior normal/failure, function-specific boundary, persistence, replay, authority, contract and integration. Missing fields, stale versions, wrong-owner input, prohibited reverse writes, projection/observation values, and out-of-scope similarly named state must not produce a successful result or modify canonical pre-state. S1.02.07 must preserve Frozen root ID/version/owner/causal references, and its persistence/replay evidence must remain deterministic.

The Frozen dependency graph makes S1.02.07 a blocking prerequisite for S1.02.08 Snapshot / Reload Identity Continuity and several later interface consumers. This evidence therefore closes only S1.02.07; it does not admit or implement those consumers.

## Implementation Decision

A dedicated implementation-level Rust crate was introduced:

- `production/crates/cross-reference-core`
- package: `gaonn-cross-reference-core`
- runtime dependencies: `gaonn-identity-core`, `gaonn-retention-core`, `gaonn-world-core`
- test-only dependencies: `gaonn-creation-boundary-core`, `gaonn-lifecycle-core`, `gaonn-retirement-state-core`

The Frozen source requires allowed transitions but does not define a universal reference lifecycle graph. The implementation therefore validates a caller/source-supplied `allowed_transitions` set rather than inventing a hidden global transition table. This is an implementation decision only and does not alter Frozen WHAT/HOW/ORDER semantics.

A source-provided `ReferenceTargetSnapshot` is used as the read-only identity target evidence. The contract requires the target to be retained, owned by PA-003, and to match exact Stable ID, namespace, namespace version, entity version, lifecycle lineage and evidence digest. The target state can be active, inactive, tombstone or retired; no name, display projection, observer output or threshold determines identity validity.
