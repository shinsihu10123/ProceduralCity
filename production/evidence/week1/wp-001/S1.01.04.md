## Frozen behavior implemented

- A Canonical write declaration must carry Fact ID, exact Authority reference, Owner, Writer, registered write interface, declaration/interface versions, Authority Epoch, canonical boundary result and causal parent.
- The exact active Authority Registry entry is resolved before any permit-like validation receipt is produced.
- Owner, writer, authority epoch and write-interface binding must match the registered authority.
- The source boundary must be Canonical and must preserve the same fact/authority/owner/writer references established by S1.01.03.
- Derived, transient-cache and observation-layer sources cannot declare Canonical write authority.
- Unknown interfaces, wrong owner/writer, stale epoch, mismatched authority and wrong interface version are rejected before canonical commit.
- A successful result is only a versioned validation receipt. It does not mutate Canonical State and does not pre-empt later transaction/commit WPs.
- Write-interface catalog snapshot/restore and replay preserve deterministic Evidence identity.
