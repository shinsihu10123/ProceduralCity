## Frozen behavior implemented

- Canonical source, Derived state, transient cache and observation view are represented as distinct authority layers.
- Canonical registration validates the exact active Authority Registry reference and owner/writer.
- Derived/cache values retain the canonical dependency reference and an invalidation lineage key, but receive no canonical authority.
- Observation views are read-only.
- Derived/cache/observation → Canonical reverse writes are explicitly rejected before any canonical mutation.
- A canonical source version change marks dependent derived/cache state stale; recomputation advances only the derived state version.
- Modifying or removing derived/cache state leaves the canonical Authority Registry Evidence digest unchanged.
- Logical snapshot/restore and deterministic replay preserve dependency version, stale state, invalidation order and Evidence digest.
