# Living World V4

작은 정착지와 12개 국가가 같은 월별 세계 장부 안에서 계속 변화하는 WebGL2 3D 사회 시뮬레이션입니다. 종료 연도와 미리 계산된 최종 결과는 없습니다. 재생할 때마다 직전 달의 인구·생산·재고·가격·재정·무역·외교·이주·기후 상태로 다음 달을 생성합니다.

V4는 V3의 121개 고정 스냅샷을 재생하지 않습니다. V3의 지형·필지·PBR 건축 조립 자산은 검증된 시각 기반으로 재사용하고, 실행 엔진과 시간 UI는 `src/v4/`의 연속 상태 모델로 교체했습니다.

## 현재 구현

- 무제한 생성 시간: 월 단위 진행, 생성된 역사만 탐색, `현재` 끝점이 계속 확장
- 12개 국가와 66개 양자관계: 신뢰·긴장·관세·통상협정·동맹·제재·국경위기·무력충돌·휴전
- 인구: 아동·청년·생산연령·고령층의 출생·사망·연령이동·쌍방 국제이주
- 경제: 노동·자본·기술·인프라 생산, 5개 상품군, 재고–공급–사용 장부, 상대가격과 물가
- 국제경제: 거리·경제규모·개방도·관세·신뢰·제재·분쟁을 반영한 양자 교역과 방향별 흐름
- 정부·정치: 조세·현금·부채·이자·사회지출·공공투자·국방·기후적응, 선거·지도부 및 체제 전환
- 자원·환경: 식량·에너지·원자재 안보, 재생에너지 전환, 배출·대기 탄소·온도·해수면, 재난 피해
- 도시: 연령대·가구·기업·고용·주택·임대료·재정·부채·교통·전력·상수도·환경을 국가 상태와 결합
- 도시 개발: 수요·수익률·금리·재정·도로 접근·경사·수공간·용도에 따라 착공, 포화 뒤 철거·재개발
- 3D 상호작용: 수도 선택, 관계 상태별 연결선, 방향성 무역·이주 입자, 선택 국가의 모든 상대국 장부
- 기존 3D 품질 유지: 지형 추종 도로와 교량, 창호·문·지붕·발코니·포디움·설비, 절차적 PBR 재질

## 조작

- 재생/일시정지: `Space`
- 1개월 이동: `←` / `→`
- 1년 이동: `Shift` + `←` / `→`
- 생성된 현재: `End` 또는 `현재`
- 세계 화면: 상단 `세계`; 수도를 누르거나 상세 패널의 국가 선택 사용
- 과거 탐색: 시간축을 움직이면 생성된 역사만 조회하며 미래를 임의 생성하지 않음

## 실행과 검증

```bash
python3 -m http.server 4173
npm test
```

런타임은 외부 CDN에 의존하지 않습니다. `?seed=원하는값`을 붙이면 같은 규칙에서 다른 지형과 사건열을 생성합니다.

자동 검사는 다음을 확인합니다.

- 같은 시드의 결정론과 월별/연별 배치 진행의 동일성
- 300년 이상 연속 진행과 120년 제한 부재
- 국가 인구 합계, 양자 수출=수입, 국제 이주 유입=유출 보존
- 12개 국가·66개 관계의 유한값과 허용 범위
- 장기 도시 성장, 건축·도로 발생, 국가 상호작용 사건
- 오래된 역사의 적응형 체크포인트와 최근 월별 기록의 메모리 상한
- V4 전용 HTML, 로컬 Three.js, 국가 선택·현재 시점 UI 계약

## 구조

```text
index.html
└─ src/v4/main.js
   ├─ world-simulation.js                국가·경제·무역·외교·기후 연속 엔진
   ├─ settlement-system.js               도시 인구·토지·건축·재정·기반시설
   ├─ macro-view.js                      동적 국가 관계·흐름 3D
   └─ app.css                            관찰 중심 UI

src/v3/
├─ macro-world.js + spatial.js           물리 세계·정착지 지형·도로 후보망
├─ geometry.js + materials.js            PBR 건축·도로·식생
└─ scene.js                              공용 WebGL 장면과 동적 재구축
```

모델 근거와 결산 순서는 [V4 연속 세계 설계](docs/v4-continuous-world.md), 수치 검증은 [V4 검증 기록](docs/v4-validation.md)에 정리했습니다.

## 현실성의 범위

V4는 결과표가 아니라 인과·확률·보존식으로 움직이는 **합성 사회 시뮬레이션**입니다. 실제 국가를 예측하는 계량모형이나 특정 도시의 디지털 트윈은 아닙니다. 실측 예측 단계에는 실제 DEM·지적·건축·교통·인구 코호트·산업연관표·재정·무역 자료에 대한 지역별 보정과 불확실성 검증이 추가되어야 합니다.
