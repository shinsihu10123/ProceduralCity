# Procedural City

도시계획 규칙과 기반시설을 반영하여 지형, 도로, 대중교통, 필지, 토지 이용, 건축물, 녹지를 자동 생성하는 WebGL2 기반 3D 도시 웹 앱입니다. 별도의 패키지나 빌드 도구 없이 정적 파일만으로 실행됩니다.

## v0.3-alpha 핵심 개선

### 도시 구조

- 셀 단위를 실제 미터 단위로 해석하는 도시 스케일
- 간선도로, 보조간선도로, 생활도로의 3단계 도로 위계
- CBD, 부도심, 산업 거점, 공원 거점, 공공시설 거점
- 도심 접근성, 도로 접근성, 경사도, 수변 접근성을 반영한 용도 배치
- 도시 유형별 생성 규칙: 균형형, 대도시형, 생태형, 수변형, 산업형

### 자연환경과 기반시설

- 다중 옥타브 노이즈 기반 지형
- 경사도에 따른 개발 제한과 보전녹지
- 시드와 도시 유형에 따라 생성되는 하천 및 수변 공간
- 수공간을 횡단하는 교량과 교각
- 중앙 경전철 노선, 3개 역, 승강장과 캐노피
- 보도, 중앙분리대, 차선, 횡단보도, 신호기, 가로등, 차량

### 건축과 공공공간

- 단독주택
- 판상형 공동주택
- 주거 타워
- 복합용도 건물
- 업무 타워
- 산업·물류 창고
- 공공시설 복합동
- 건축 유형별 포디움, 셋백, 옥상 설비, 창호, 발코니, 출입구 표현
- 공원, 광장, 수공간, 가로수와 조경

### 시각화와 조작

- 시간대에 따른 태양 방향, 하늘색, 안개, 야간 창 조명
- 조감, 가로, 도심, 초기화 카메라 프리셋
- 마우스, 트랙패드, 터치 회전·이동·핀치 확대
- 자동 회전
- 나침반과 동적 축척 표시
- 도시 규모에 따른 자동 세부도 조절

### 도시 지표

- 건축물 수
- 추정 거주 인구
- 추정 일자리
- 평균 건축물 높이
- 녹지율
- 도로 연장
- 대중교통 접근률
- 직주 균형 지수
- JSON 스키마 v3 내보내기

## 실행

정적 파일을 로컬 서버에서 제공합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속합니다.

## GitHub Pages

저장소의 **Settings → Pages → Build and deployment → GitHub Actions**를 선택합니다. `main` 브랜치에 변경 사항이 병합되면 `.github/workflows/pages.yml`이 자동으로 배포합니다.

## 저장소 구조

```text
ProceduralCity/
├── .github/workflows/pages.yml
├── docs/
│   ├── architecture.md
│   └── realism-roadmap.md
├── index.html
├── src/
│   ├── main.js
│   ├── main.part1.js.txt
│   ├── main.part2.js.txt
│   ├── main.part3.js.txt
│   ├── main.part4.js.txt
│   └── style.css
├── LICENSE
└── README.md
```

`src/main.js`는 네 개의 소스 조각을 순서대로 불러와 하나의 ES 모듈로 실행합니다. 이 구조는 GitHub Contents API의 파일 크기와 작업 안정성을 고려한 임시 배포 구조입니다.

## 현재 한계

- 실제 지도, 지적도, DEM이 아닌 가상 도시입니다.
- 차량과 인구는 시각적·통계적 추정치이며 동적 교통 시뮬레이션이 아닙니다.
- 건물은 절차적 매스 모델이며 실제 BIM 수준의 상세 모델이 아닙니다.
- 실시간 그림자, 반사, 물리 기반 재질은 아직 적용되지 않았습니다.
- 도로는 지형에 적응하지만 완전한 토목 선형 설계와 절성토 계산은 수행하지 않습니다.
