# Procedural City

브라우저에서 바로 실행되는 절차적 생성 기반 3D 도시 웹 앱입니다. WebGL2를 직접 사용하므로 별도의 빌드 도구나 패키지 설치가 필요하지 않습니다.

## 현재 버전

`v0.2-alpha — Realistic Urban Structure`

단순 격자형 랜덤 도시에서 벗어나 지형 적합도, 도로 위계, 중심지 접근성, 용도 집적, 공원과 건축 유형을 반영하기 시작한 단계입니다.

## 현재 기능

- 문자열 시드 기반의 재현 가능한 도시 생성
- 도시 규모에 맞춰 정규화된 절차적 지형
- 필지별 경사도와 개발 적합도 판정
- 급경사지 녹지 보전
- 간선·보조간선·생활도로 계층
- 보도와 차선 중심선
- CBD, 두 개의 부도심, 산업 거점, 공원·공공시설 거점
- 접근성 기반 주거·상업·산업·공공 용도 집적
- 단독주택, 공동주택, 타워, 복합용도, 산업·공공시설 유형
- 층수와 유효면적률 기반 연면적 계산
- 추정 거주 인구, 일자리, 평균 높이, 녹지 비율 계산
- 회전·확대·이동 가능한 3D 뷰어
- 생성 결과 JSON 내보내기
- 모바일·태블릿 반응형 레이아웃

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속합니다.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**로 이동
2. **Build and deployment**에서 **GitHub Actions** 선택
3. `main` 브랜치에 푸시하면 자동 배포

## 구조

```text
ProceduralCity/
├── .github/workflows/pages.yml
├── docs/architecture.md
├── index.html
├── src/main.js
├── src/style.css
├── LICENSE
└── README.md
```

GitHub 배포본에서는 연결 도구의 파일 크기 제약 때문에 실행 엔진이 `main.part*.js.txt` 파일로 나뉘어 있고, `src/main.js`가 이를 순서대로 결합한다. 실행 결과는 단일 원본과 동일하다.
