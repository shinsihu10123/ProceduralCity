# Deep Time V5

기원전 12,000년의 이동형 수렵·채집 집단에서 출발해 정착지·농경·도시·국가·교역망·전쟁이 하나의 거대한 3D 공간에서 내생적으로 발생하는 무제한 문명 시뮬레이션입니다.

V5에는 처음부터 존재하는 도시, 국가, 국경, 도로, 산업 또는 고정된 미래 결과가 없습니다. 각 연도의 인구·식량·자원·기술·이동 비용·교역·정치 응집력·갈등 상태가 다음 연도를 계산합니다. 같은 시드는 재현 가능하고, `?seed=다른값`은 같은 규칙으로 다른 세계사를 만듭니다.

## V5 핵심

- 원시 기원: 8개 이동형 수렵·채집 집단, 약 400명, 국가 0개, 상설 도시 0개
- 단일 세계: 2,400km급 대륙·해양·산맥·기후대·유역·자원이 한 WebGL 장면에 존재
- 실제 지형 비용: 경사·고도·생물군계·하천·해양을 반영한 최소비용 이동 경로
- 내생 정착과 도시화: 식량 저장·수원·인구 압력·농경 채택·이주로 야영지→촌락→마을→도시가 전환
- 내생 국가: 잉여·상설 정착·공동 방어·재분배가 축적될 때 추장사회와 국가가 형성
- 기술 확산: 날짜 자동 해금 없이 자원 접근, 인구, 잉여, 문화 접촉, 교역을 통해 연구·모방
- 물류와 교통: 식량·목재·석재·금속·수공품·연료의 실제 재고 이동, 여행·지역 교통·이주
- 전쟁: 자원 압력·접경 경쟁·신뢰·무역 의존·군사력에서 전쟁이 발생하고 군대가 지형 경로를 따라 이동
- 직접 시각화: 물류 차량·보행/차량 교통·이주 집단·군대·전투·연기·건설·도로 승격·국경 변화
- 무제한 시간: 종료 연도 없음, 생성된 역사만 되감기, 장기 기록은 적응형 체크포인트로 보존

## 하나의 공간

V4의 `정착지 ↔ 세계` 화면 전환은 제거했습니다. 대륙·국가·도시·건물은 동일 좌표계에 있으며 `대륙 / 권역 / 생활권` 버튼은 지도를 바꾸지 않고 카메라 거리만 바꿉니다. 렌더링 기준은 1 단위 = 100m이며 로그 깊이 버퍼와 거리별 세부 표현을 사용합니다.

## 조작

- 재생/일시정지: `Space`
- 1년 이동: `←` / `→`
- 100년 이동: `Shift` + `←` / `→`
- 생성된 현재: `End` 또는 `현재`
- 같은 공간의 카메라 거리: 상단 `대륙 / 권역 / 생활권`
- 생활권 선택: 지도 위 표식 또는 상세 패널의 선택 목록
- 시드 변경: `?seed=my-world`
- 지형 해상도: `?size=72`~`?size=128` (기본 112)

## 실행과 검증

```bash
python3 -m http.server 4174
npm test
```

외부 CDN 없이 저장소의 Three.js 런타임만 사용합니다. 자동 검사는 원시 초기조건, 결정론, 120년 초과 진행, 내생 농경·정착·복수 국가, 최소비용 교통망, 물류·교통·이주·군대 흐름, 전쟁·전투 발생, 장기 유한값과 적응형 역사를 확인합니다.

## 구조

```text
index.html
└─ src/v5/main.js
   ├─ prehistoric-world.js   인구·식량·자원·기술·정착·국가·무역·전쟁 엔진
   ├─ unified-scene.js       단일 지형·생활권·도로·물류·교통·전투 3D
   └─ app.css                관측 중심 반응형 UI

src/v3/macro-world.js        판 구조·기후·수문 기반 물리 세계 생성
src/v4/                      이전 연속형 현대 세계 엔진 보존
```

세부 인과 규칙과 근거 자료는 [V5 심층 역사 설계](docs/v5-deep-time.md), 검증 항목은 [V5 검증 기록](docs/v5-validation.md)에 정리했습니다.

## 현실성의 범위

V5는 미리 만든 역사 애니메이션이 아니라 상태·제약·확률로 움직이는 합성 문명 모델입니다. 모든 시민 한 명을 개별 렌더링하는 모델이나 실제 지구 역사를 재현하는 디지털 트윈은 아닙니다. 화면의 이동체와 건물은 전체 흐름을 대표하는 물리 스케일 표본이며, 실제 지역 예측에는 실측 DEM·고기후·고고학 유적·토양·자원·인구 자료를 이용한 지역 보정이 추가로 필요합니다.
