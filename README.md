# Living Settlement V3

작은 정착지가 주택·일자리·공공서비스·재정·환경·교통의 상호작용에 따라 120년 동안 성장하는 과정을 직접 탐색하는 WebGL2 3D 시뮬레이션입니다.

V3는 이전 화면과 엔진을 이어 붙인 업데이트가 아닙니다. `index.html`은 `src/v3/`와 고정 버전 Three.js만 불러오며, V0–V2 런타임은 실행 경로에 포함되지 않습니다.

## 현재 구현

- 3,600km 합성 세계: 128×128 고도·기후 격자, 13개 판, 12개 국가, 하천과 18개 교역 회랑
- 2.4km 정착지: 160×160 지형, 수계, 경사·물·범람 비용을 반영한 39개 도로와 2개 교량
- 도로 전면 필지 319개: 경사 제한, 수공간 회피, 기능별 입지와 밀도 제약
- 120년 인과 시뮬레이션: 42명·14가구에서 시작해 연도별 출생·사망·이동, 주택, 고용, GDP, 재정, 서비스, 기반시설, 환경을 계산
- 기능형 건축: 주거·상업·공업·복합·교육·보건·교통·기반시설 20개 원형
- PBR 기반 3D: 절차적 벽돌·미장·콘크리트·아스팔트·기와·유리·수면 재질, 창호·문·지붕·발코니·포디움·옥상설비·공사 상태
- 최소 UI: 초기/최종 이동, 직접 스크럽, 재생 속도, 세계/정착지 전환, 카메라 시점, 필요할 때만 여는 상세 패널

## 실행

정적 서버에서 루트를 제공합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 런타임은 외부 CDN에 의존하지 않습니다.

## 검증

```bash
npm test
```

검사는 결정론, 도로의 지형 관통·수공간 침범, 교량, 필지 전면, 121개 시점의 재고-흐름, 건물·도로 재고의 단조 증가, 세계 국가·하천·교역, V3 전용 HTML 계약을 확인합니다.

기준 시드의 검증 결과는 다음과 같습니다.

| 완공 건축물 | 15동 | 172동 |

## 구조

```text
index.html
└─ src/v3/main.js
   ├─ macro-world.js + macro-view.js     세계·국가·교역
   ├─ spatial.js                         지형·수계·도로·필지
   ├─ simulation.js                      사회·경제·환경 시간축
   ├─ geometry.js + materials.js         건축·도로·식생·PBR
   └─ scene.js + app.css                 렌더러·카메라·최소 UI
```

조사부터 검토까지의 결정과 현실성 범위는 [V3 재구축 기록](docs/v3-rebuild.md), 실제 브라우저 검증값은 [V3 검증 기록](docs/v3-validation.md)에 정리했습니다.

## 현실성의 범위

현재 버전은 규칙과 제약을 가진 **합성 시뮬레이션 기반선**입니다. 실제 국가 경계, 지적도, 건축물대장, 교통량, 정밀 DEM을 복제한 디지털 트윈은 아닙니다. 실측 기반 단계에서는 Copernicus DEM·OpenStreetMap·CityGML/CityJSON·3D Tiles와 지역 통계의 좌표계·라이선스·검증 절차가 추가되어야 합니다.
