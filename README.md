# Procedural City

실제 도시가 만들어지는 순서를 모사하는 WebGL2 기반 절차적 3D 도시 생성기입니다. 지형과 도시를 따로 무작위 생성해 겹치는 방식이 아니라, **지형·수문 → 중심지 → 도로 위계 → 가로망 → 필지 → 토지이용·밀도 → 건축 형태 → 교통·녹지**의 의존 관계를 하나의 결정론적 공간 모델로 계산합니다.

현재 버전은 **v1.1 Reality Engine alpha**입니다. 별도의 런타임 패키지나 서버 없이 정적 파일만으로 실행되며 GitHub Pages에 배포됩니다.

## v1.1 핵심 개선

### 지형·수문 시스템

- 다중 옥타브 지형과 열적 침식
- Priority-Flood 방식의 배수 연결성 보정
- D8 흐름 방향과 누적 유량
- 하천 강도, 수변 거리, 토양, 식생, 침수 위험, 개발 적합도 필드
- 급경사지·수공간·범람 위험지의 개발 억제

### 도시 형태 시스템

- CBD·부도심·고용 거점의 다핵 구조
- 경사·수공간·침수·식생 비용을 반영한 간선도로 경로 탐색
- 지형 등고 방향을 따르는 2계열 가로망
- 간선·집산·생활도로의 3단계 위계와 곡선 회랑
- 모든 필지를 도로 전면에 맞추어 생성하고 중복 필지를 공간 해시로 제거
- 중심지·대중교통·도로 등급·수변·경사에 따른 용도와 용적 배정
- 500 m 역세권 접근성과 침수 노출 지표

### 건축·시각 시스템

- 단순 상자 반복 대신 형태 문법 기반 복합 매스
- 모따기형, L자형, 중정형, 판상형, 계단형 타워, 타원형 타워, 산업용 박공지붕
- 포디움·셋백·테라스·발코니·입구 캐노피·옥상 기계실·태양광 패널
- 재질 판별형 셰이더와 절차적 창호 분할
- 카메라 기반 Fresnel 반사, 젖은 노면 반응, 수면 미세 파동, 대기 원근, ACES 계열 톤 매핑
- 곡선 선형을 따르는 차량과 노면전차

## 생성 파이프라인

```text
사용자 시나리오·시드
→ 지질성 고도장·열적 침식
→ 배수 보정·유역 누적·수계 추출
→ 개발 적합도·침수 위험
→ 다핵 중심지 선택
→ 지형 비용 간선도로·집산도로
→ 등고 방향 생활가로망
→ 도로 전면 필지 분할
→ 접근성 기반 용도·용적률
→ 형태 문법 건축·공원·대중교통
→ 도시 지표·WebGL 메시
→ 시간·기상 기반 물리 조명
```

## 실행

정적 파일을 로컬 서버에서 제공합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 또는 `http://localhost:4173/v110.html`을 엽니다.

## 자동 검증

```bash
node scripts/validate-engine.mjs
node scripts/test-v11-core.mjs
node scripts/test-v11-render.mjs
```

검증 항목은 다음과 같습니다.

- 34개 엔진 레이어의 로딩 순서·구문·DOM 계약
- 배수망과 침수 필드의 유효성
- 동일 시드의 중심지·도로·필지 재현성
- 필지의 도로 전면 연결, 수공간 침범 및 경사 제한
- 도로 위계·역·건축·공원 최소 구성
- 전체 렌더 버퍼의 유한값·정점 스트라이드·도시 지표

GitHub Pages 배포 전에 동일 검사가 Actions에서 자동 실행됩니다.

## 현실성의 범위

이 프로젝트는 도시계획 규칙을 적용한 **합성 도시 모델**입니다. 실제 서울의 지적도·건축물대장·DEM·교통량을 복제한 디지털 트윈은 아닙니다. 현재 결과는 CityGML의 의미상 LOD2에 가까운 외부 매스와 도시 객체 관계를 목표로 하며 BIM 내부 공간, 실제 구조 계산, 법정 인허가, 정밀 토목 설계를 대체하지 않습니다.

설계 근거와 알고리즘 대응 관계는 [v1.1 현실성 엔진 설계 문서](docs/v1.1-reality-engine.md)에 정리되어 있습니다.
