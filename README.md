# Procedural City · Living World Engine

국가 규모의 물리 세계에서 작은 정착지가 사회·경제·환경 시스템의 결과로 성장하는 과정을 보여 주는 WebGL2 기반 다중 해상도 3D 시뮬레이터입니다. 지형과 도시를 따로 무작위 생성해 겹치거나, 연도별 건물을 미리 예약하지 않습니다. **지각·기후·수문 → 국가·자원·교역 → 정착 입지 → 가구·기업·정부 → 주택·기반시설 → 도로·필지·건축**의 인과 관계를 같은 시드와 재고-흐름 모델에서 계산합니다.

현재 버전은 **v2.0 Living World Engine alpha**입니다. 별도의 런타임 패키지나 서버 없이 정적 파일만으로 실행되며 GitHub Pages에 배포됩니다.

## v2.0 핵심 개선

### 여러 국가가 들어가는 물리 세계

- 기본 2,400 km 폭, 96 × 96 거시 격자
- 11~15개 판의 이동·경계 수렴을 반영한 융기장
- 열적 지형 완화, 위도·고도·해양 거리 기반 기온·강수
- Priority-Flood 계열 배수 보정과 D8 하천 누적
- 8~14개 합성 국가, 수도·항구·자원·제도·경제 재고
- 경제 규모·거리·자원 보완성·개방도를 반영한 교역 회랑
- 국가 세계 3D와 미터 단위 정착지 3D를 즉시 전환하는 다중 LOD

### 내생적 사회·경제 성장

- 실제 소규모 가구 표본과 규모 확장 시 대표 가중치
- 8개 업종 기업의 고용·생산·매출·이윤·투자·진입·퇴출
- 노동·상품·수입/수출·주택·임대료·토지가격 시장
- 출생·사망·순이동의 월별 인구 재고-흐름
- 지방정부 세입·세출·현금·부채·공공사업·선거 대응
- 전력·상수·하수·폐기물·배수, 교육·보건·응급·공원
- 배출·대기·수질·불투수율·집중호우 피해
- 주택 부족·사업성·시공 능력과 정부 재정이 실제 3D 건설량을 결정

### 성장 3D 시각화

- 지형·자연은 유지하고 건물과 도로를 의미 객체별 정점 청크로 분리
- 초기 기준 시드: 42명, 14가구, 6개 기업, 7개 건물, 5개 도로 회랑
- 건설된 건물의 도로 전면 ID를 따라 필요한 도로가 함께 개통
- 인구·재정 조건이 맞을 때만 대중교통 메시 활성화
- 세계/정착지 보기, 실행/정지, 1년 진행, 0.5개월~5년/초 속도

## v1.1에서 계승한 도시 현실성 엔진

### 지형·수문 시스템

- 다중 옥타브 지형과 열적 침식
- Priority-Flood 방식의 배수 연결성 보정
- D8 흐름 방향과 누적 유량
- 하천 강도, 수변 거리, 토양, 식생, 침수 위험, 개발 적합도 필드
- 급경사지·수공간·범람 위험지의 개발 억제

### 도시 형태 시스템

- CBD·부도심·고용 거점의 다핵 구조
- 경사·수공간·침수·식생 비용을 반영한 간선도로 경로 탐색
- 지형 등고 방향을 따르는 2계열 가로망
- 간선·집산·생활도로의 3단계 위계와 곡선 회랑
- 모든 필지를 도로 전면에 맞추어 생성하고 중복 필지를 공간 해시로 제거
- 중심지·대중교통·도로 등급·수변·경사에 따른 용도와 용적 배정
- 500 m 역세권 접근성과 침수 노출 지표

### 건축·시각 시스템

- 단순 상자 반복 대신 형태 문법 기반 복합 매스
- 모따기형, L자형, 중정형, 판상형, 계단형 타워, 타원형 타워, 산업용 박공지붕
- 포디움·셋백·테라스·발코니·입구 캐노피·옥상 기계실·태양광 패널
- 재질 판별형 셰이더와 절차적 창호 분할
- 카메라 기반 Fresnel 반사, 젖은 노면 반응, 수면 미세 파동, 대기 원근, ACES 계열 톤 매핑
- 곡선 선형을 따르는 차량과 노면전차

## 생성 파이프라인

```text
시드
→ 판·대륙·융기·기후
→ 배수 보정·하천·생물군계
→ 국가·자원·제도·교역
→ 정착 적합지
→ 가구·기업·정부·시장
→ 민간 개발·공공 기반시설
→ 지형 비용 도로·가로 전면 필지
→ 형태 문법 건축·공원·대중교통
→ 건설 재고에 따른 3D 정점 활성화
→ 사회·경제·환경 지표와 시간 진행
```

## 실행

정적 파일을 로컬 서버에서 제공합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 또는 `http://localhost:4173/v110.html`을 엽니다.

## 자동 검증

```bash
node scripts/validate-engine.mjs
node scripts/test-v11-core.mjs
node scripts/test-v11-render.mjs
node scripts/test-v2-world.mjs
node scripts/test-v2-society.mjs
node scripts/test-v2-integration.mjs
```

검증 항목은 다음과 같습니다.

- 38개 엔진 레이어의 로딩 순서·구문·DOM 계약
- 배수망과 침수 필드의 유효성
- 동일 시드의 중심지·도로·필지 재현성
- 필지의 도로 전면 연결, 수공간 침범 및 경사 제한
- 도로 위계·역·건축·공원 최소 구성
- 전체 렌더 버퍼의 유한값·정점 스트라이드·도시 지표
- 세계 생성 결정론, 배수 방향, 국가·교역·정착지 유효성
- 100년 사회 시뮬레이션의 인구·주택·노동·재정 회계
- 초기 취락과 성장 후 정착지의 건물·도로·정점 단조 증가

GitHub Pages 배포 전에 동일 검사가 Actions에서 자동 실행됩니다.

## 현실성의 범위

이 프로젝트는 물리·도시계획·행위자 규칙을 적용한 **합성 세계·도시 모델**입니다. 실제 지구의 국경, 서울의 지적도·건축물대장·DEM·교통량을 복제한 디지털 트윈이 아닙니다. 현재 결과는 CityGML의 의미상 LOD2에 가까운 외부 매스와 도시 객체 관계를 목표로 하며 BIM 내부 공간, 실제 구조 계산, 법정 인허가, 정밀 토목·수리 설계, 정책 예측을 대체하지 않습니다.

조사 근거는 [v2.0 조사 보고서](docs/v2-living-world-research.md), 전체 데이터 흐름은 [v2.0 시스템 아키텍처](docs/v2-systems-architecture.md), 시험 결과와 한계는 [v2.0 검증 보고서](docs/v2-validation.md)에 정리되어 있습니다.
